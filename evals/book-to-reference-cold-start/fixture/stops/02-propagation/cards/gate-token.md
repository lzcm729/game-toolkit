# 先辨认一处闸口

## R — 原文

> Place the blue token beside the gate before moving a ribbon.
>
> 译：移动纸带之前，先把蓝色标记放在闸口旁。
>
> — Nera Sample, The Ribbon Harbor Notebook, p.2

## I — 方法骨架

从可辨认输入得到有限的观察记录，不把记录当批准设计。

## A1 — 书中案例

书中的编造演练只说明本步骤，不证明其他项目的效果。

## A2 — 触发场景

- 两个人指的不是同一个闸口，先怎么核对？
- 地点名字太像，移动纸带前该确认什么？

**与相邻卡的区分**

- 与 `single-vane` 区分：本卡先确认闸口身份；只有身份一致后，才用后者改变一个泊位的风牌并记录观察。

## E — 执行

### 分支 1（u01-01）

- 输入：已辨认地点与当前记录。
  1. 先放蓝筹并让两人指向同一闸口；不同就停（p.2）。
- 输出：观察记录；条件不符先停止，不补造通过。

## B — 边界

原书未说明量化通过阈值。分支 1 不授权真实港口操作。
