# 核心愿景与目标体验 (Vision)

**理论基础**: Schell Lens #11 统一、Lens #2 本质体验、Lens #111 责任

**关注点**:
- 设计是否支持本项目**已明确声明**的核心愿景、目标玩家、目标体验
- 关键机制与体验目标之间是否存在可解释的因果关系
- 是否存在与明确目标冲突的设计，冲突证据是什么
- 道德选择、叙事表达等维度，**仅在项目明确将其列为目标时**才检查

**Prompt 模板**:
```
从【核心愿景与目标体验】视角评审此设计文档。

先读取任务提供的「项目愿景上下文」，按其状态执行：

【resolved：目标明确】
逐项检查「目标 → 相关机制 → 预期体验」的因果关系。
结论区分：支持 / 冲突 / 证据不足。
指出冲突时必须同时引用目标来源和被评审的设计。

【missing：没找到明确目标】
切换为「目标明确性检查」：
- 本视角结论标记「愿景一致性：无法判断」
- 检查当前文档是否说清了目标玩家、目标体验、核心决策与取舍原则
- 指出哪些设计决策因目标缺失而无法评价
- 最多列 3 个需要项目负责人拍板的问题
不得推断「项目没有愿景」，只能说「已检查来源中未找到」。
不得因为无法证明符合愿景，就判定设计偏离愿景。
可以提候选目标，但必须标注「待确认建议」，不得用它评价当前设计。

【conflicting：来源冲突】
列出冲突原文、来源、受影响的设计判断。
暂停依赖冲突目标的结论，其余有共同依据的部分继续检查。
需要裁决的问题交回主流程，不自行选一个来源充当事实。

标注严重程度（🔴高 / 🟡中 / 🟢低）。不为凑数制造发现。
```
