# 一句话

篝火晚会上谁能吃、吃什么、吃出什么，全由当天鱼缸里剩下的鱼决定。

# 规则

## 谁能吃

- 只有当晚在营地的猫能吃鱼，离线或掉线的猫不参加。
- 一只猫每晚最多吃三条，第四条被拒绝并提示「吃不下了」（快照）。
- 鱼缸里的鱼谁都能拿去吃，先拿先得，不看是谁钓的。

## 吃了怎样

- 每种鱼给一层限时增益，持续到下一次入夜；同种鱼再吃只刷新时长，不叠层。
- 增益的种类与强度按鱼表「吃鱼效果」列配，本页不列数值。
- 吃过的鱼从鱼缸移除，不再能献祭或出售。

## 什么时候吃

- 入夜后篝火点亮才能吃，白天鱼缸只进不出。
- 献祭先于吃鱼：祭坛发起倒计时期间不能开吃。

# 接口

- 鱼表持有每种鱼的增益种类、强度与可食用资格。
- 局与进程提供入夜、翻天信号，本页只消费。
- 联机册定谁「在营地」，本页只读这个状态。
