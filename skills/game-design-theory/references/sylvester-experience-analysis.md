# 体验分析：事件、价值与情绪

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> Game designers don’t design events. We design systems of mechanics that generate events.
>
> 译：游戏设计师不设计事件。我们设计的是生成事件的机制系统。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Mechanics and Events, p.8

> What’s emotionally relevant about an event is not the event itself, but the changes in human values implied by that event. The more important the human value and the more it changes, the greater the emotion.
>
> 译：一个事件在情绪上要紧的不是事件本身，而是它暗含的 human value 变化。价值越重要、变化越大，情绪越强。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Emotion and Change, p.13

> Even events that seem to be very minor in themselves can be emotional if they have important implications.
>
> 译：本身看来微不足道的事件，只要后果重大，也能带出情绪。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Emotion and Change, p.13

## I — 方法骨架 (Interpretation)

这张卡回答「这段游玩为什么没感觉、情绪为什么不够强」。作者的链条是：设计师做机制，外面包一层 fiction（虚构：图像、声音、名字、设定）；游玩时机制和玩家互动生成事件；事件触发情绪；情绪合成体验（p.44）。设计师只能改机制，事件是生成出来的（p.8）。事件要有意义就得引发情绪（p.8）。情绪来自事件暗含的 human value 变化。human value 指人在乎、能在几个状态之间迁移的东西，写成 [life/death]、[victory/defeat] 这样的对；只有在正、中、负之间跨状态的变化才算数，预期中的变化和信息揭示也算（p.12–15）。implications 指事件对更大局面的后果。

四个分支：分支 1 逐环复盘，找出不引发情绪的断环；分支 2 把一段游玩的事件反推到机制；分支 3 对关键事件做价值分析，排相对强弱；分支 4 给平淡的小事件挂上更大的后果。常规顺序 1→3→4，任何改动最后都经分支 2 写成机制改动。

作者观点（只作参考）：察觉细微情绪是设计师的技能（p.9）；目标情绪别只写 fun（p.10）。

## A1 — 书中案例 (Past Application)

- **分支 1｜原书未提供完整复盘案例，以下是合成演练**：手机消除的限时连锁模式。机制：交换、三消、连锁、60 秒计时；fiction：糖果工坊；事件：最后 5 秒五连锁、差 1 分没达标；情绪：狂喜、懊恼。普通三消标为不引发明显情绪的断环，交分支 3。
- **分支 2｜Super Mario Galaxy 熔岩（作者亲历，p.7–8）**：事件是起跳、失误、碰熔岩、着火弹飞、惨叫、空中操控落回地面；机制是跳跃键、重力、碰撞、熔岩反应，以及作者自己的空中操控。光盘里只有机制，这串事件不会以同样方式重演。示范性质。
- **分支 3｜丢兵（例题，p.13）**：开局丢兵只是小麻烦，残局丢掉护王的兵就是从胜到负。转述例（p.12–13）：Minecraft 建好堡垒是危险→安全；WoW 打怪后入会是陌生→朋友、孤独→一起；押真钱的掷骰、失误挨电击的 PainStation 说明被牵动的价值也可以是真实的。
- **分支 4｜Modern Warfare 连杀（转述，p.14）**：连杀 3/7/11 分别给雷达、空袭、AC-130；第 11 杀和第 1 杀动作相同，对全局的改变大得多。作者说这个设计 works，没给数据。侦察到关键建筑能扭转败局（例题，p.13–14），这是自然存在的后果，不是设计出来的。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 试玩或复盘时觉得某段「没感觉」，说不出原因。
2. 评审意见写成「这里加个爆点」「加段剧情」，没落到规则上。
3. 想比较几个事件哪个情绪强、哪个是空的。
4. 高频小动作（拾取、击杀、收获）平淡，想让它们带分量。

**语言信号**

- 这段为什么没感觉 ／ 情绪不够强 ／ 怎么拆一段体验 ／ 这个事件有没有意义 ／ 收集太平淡 ／ 该改哪条规则
- feels flat ／ no emotional impact ／ why doesn't this moment land ／ human value ／ mechanics vs events ／ raise the stakes of small actions

**与相邻卡的区分（初稿）**

- 关键价值已锁定、比赛早早定局；顿悟揭示 → `sylvester-suspense-and-insight.md`
- 该靠奇观、美术、剧情还是机制出情绪；虚构和机制打架 → `sylvester-emotional-triggers-and-fiction.md`
- 整段情绪曲线平、没高潮；不沉浸 → `sylvester-intensity-and-immersion.md`
- 玩家说的原因能不能信、试玩怎么问 → `sylvester-playtest-observation.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 想整体复盘一个游戏或模式，不知道哪一环出问题 | 分支 1 |
| 手上有一段具体游玩，想知道该改哪条规则 | 分支 2 |
| 某些事件没感觉，想比较情绪强弱 | 分支 3 |
| 高频小事件平淡，想加分量 | 分支 4（先过分支 3） |

### 分支 1：体验引擎链复盘

- **输入**：机制说明、fiction 设定、至少一段游玩记录（录像或逐步描述）。没有游玩记录先要：事件只在游玩中生成（p.8）。
- **步骤**：
  1. 逐环写：机制 → fiction → 事件序列 → 事件触发的情绪 → 情绪合成的整体体验（p.44）。完成标准：五环都有具体内容，不从机制直接跳到体验。
  2. 逐个事件查是否引发情绪，不引发的标为断环（p.8）。完成标准：断环清单。
- **判停 / 转向**：体验一环只能描述。情绪怎样合成体验，作者只说大于各部分之和（p.34），判断好坏的判据原书未说明。断环交分支 3，要改交分支 2。以线性叙事、手工内容取胜的游戏不在本分支：「把游戏当机器」是作者的立场（p.44），这类游戏在这条链之外（编者评注，非原书）。
- **输出**（约定）：五环表 + 断环清单。

### 分支 2：事件反推机制

- **输入**：一段具体游玩。
- **步骤**：
  1. 按时间顺序列出发生的事件（p.8，Mario 示范）。完成标准：每个事件一行。
  2. 对每个事件反推生成它的机制，玩家的操作也算在内（p.8）。完成标准：每个事件至少对上一条机制。
  3. 想改某个事件，就把改动写到机制上，不写成「让某事发生 / 不发生」（p.8）。完成标准：每条改动指向具体机制。
- **判停 / 转向**：一个事件由几条机制共同生成时改哪条，原书未说明：列出候选，由设计者选。
- **输出**（约定）：「事件 → 生成它的机制（含玩家操作）」对照表 + 候选改动落点。

### 分支 3：human value 事件分析

- **输入**：关键事件清单（来自分支 1、2 或设计者）；每个事件发生时的局面（阶段、比分、处境）。局面缺了先问。
- **步骤**：
  1. 写出事件牵动的 human value，可对照作者的清单：[life/death]、[victory/defeat]、[friend/stranger/enemy]、[wealth/poverty]、[low status/high status]、[together/alone]、[danger/safety]、[knowledge/ignorance] 等（p.12）。完成标准：每个事件至少一个价值，或标「无」。
  2. 写出事件前后该价值处于正、中、负哪个状态；只有跨状态的迁移才算情绪相关（p.12）。
  3. 按事件的含义判断，不按事件本身：同样丢一个兵，开局和残局幅度不同（p.13）。
  4. 把预期中的迁移（p.14）和信息揭示（p.15）也算进来。
  5. 按「价值越重要、变化越大，情绪越强」排相对强弱，标出不牵动任何跨状态迁移的空洞事件（p.13）。完成标准：每个判断附理由。
- **判停 / 转向**：只做定性排序。原书没有刻度，不同种类的价值（财富对地位）之间怎么比也没有依据：分组列，不硬排。空洞事件想加分量 → 分支 4；关键价值已锁定 → `sylvester-suspense-and-insight.md`。
- **输出**（约定）：表，列为「事件 / 价值 / 前→后状态 / 相对强弱 / 理由」。

### 分支 4：放大小事件的后果

- **输入**：分支 3 标出的平淡小事件；所在系统里更大的局面（胜负、资源、信息）。
- **步骤**：
  1. 确认事件本身小，单看几乎不改变局面（p.13）。
  2. 给它挂上会改变更大局面的后果。作者的两类：累计阈值奖励（连杀），或让它成为关键信息的来源（侦察）（p.13–14）。完成标准：每个事件至少一条候选后果。
  3. 检查同一动作在不同情境下的价值迁移确实拉开了，例如第 11 杀比第 1 杀更改变全局（p.14）。完成标准：按分支 3 的格式写出改前、改后。
  4. 检查后果会不会因关键价值已锁定而失效（p.14–15）。
- **判停 / 转向**：阈值和后果大小原书未说明，3/7/11 只是 Modern Warfare 的现成数值，交设计者。
- **输出**（约定）：候选后果清单 + 改前改后的价值对照。

## B — 边界 (Boundary)

**不要用这张卡**

- 把分析结果当结论。情绪不报告自己的真实原因，人会自动给情绪编理由（p.16–18）；表里的判断都是假设，要靠试玩、数据或对照小改动去验证（p.19、p.48）→ `sylvester-playtest-observation.md`。

**作者警告的失败模式**

- 拿故事或电影当思考游戏的比喻，会走向预设体验，丢掉机制互动生成的体验（p.44）。
- 把建议写成直接编排事件，绕过生成事件的机制（p.8）。

**作者盲点与时代局限**

- 「所有情绪触发器底层都是 human value 变化」（p.12）没有被证明，同章的音乐、美不明显经过价值变化（p.24–26）。
- 只有定性的「越重要、越大，情绪越强」；作者自称全书是模型和假设（p.375），框架要靠经验校准（p.47）。

**各分支的已知缺口**

- 分支 1：与分支 2、3 部分重叠；体验合成没有判据。
- 分支 2：原文只有 Mario 一个拆解示范，流程是从示范重建的；改哪条机制没有判据；同一机制换个玩家会生成不同事件，对照表只对这一段游玩成立。
- 分支 3：没有刻度，不做跨类比较。
- 分支 4：作者唯一「设计出来的」放大例是连杀，侦察是自然存在的后果；3/7/11 是例子，不是建议值；放大局部事件可能加剧强者愈强，本节没有讨论，平衡问题见第 6 章的卡（`sylvester-balance-change-review.md`、`sylvester-degenerate-strategy-hunt.md`）。
