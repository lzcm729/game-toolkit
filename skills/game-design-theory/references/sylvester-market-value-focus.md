# 竞品价值对比与聚焦

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> The important values in a game are the ones that are superior to every other offering on the market. Every other value can be fulfilled better by another product.
>
> 译：一款游戏里重要的价值，是那些胜过市面上所有同类的价值。其余的价值，别的产品都能做得更好。
>
> — Tynan Sylvester, *Designing Games*, Ch10 The Market / Value Curves, p.258

> Every value costs resources. … In addition, each new value reduces the emotional purity of the experience. … Finally, some values are simply incompatible.
>
> 译：每项价值都要耗资源。……而且每多一项价值，体验的情感纯度就降一分。……最后，有些价值根本互不相容。
>
> — Tynan Sylvester, *Designing Games*, Ch10 The Market / Value Focus, p.258

> Match your ambition to your resources. … it's better to be the best at one thing than it is to be mediocre at 10 things.
>
> 译：野心要和资源相称。……在一件事上做到最好，强过在十件事上都平庸。
>
> — Tynan Sylvester, *Designing Games*, Ch10 The Market / Value Focus, p.261

## I — 方法骨架 (Interpretation)

这张卡回答「和竞品比我们到底有什么、该把力气押在哪几项上」。市场价值（market value）指游戏体验里以某种具体方式吸引某类人的一个方面，比如 The Sims 的「创意盖房」和「人生角色扮演」；它不是第 1 章讲情绪的 human value。价值曲线（value curve）把自己和相似竞品按同一组市场价值逐项评级，放在一起比。道理是：想要某项价值的玩家会去找提供得最好的那款游戏，所以只有胜过所有竞品或独有的价值才算卖点；价值又都有成本，资源越少越要集中。

三个分支：分支 1 做对比表；分支 2 用表做聚焦和价值预算；分支 3 从「像某款成功作再加点东西」这类提案进入，判断是不是树桩形，再回到分支 2。常规顺序 1→2，分支 3 需要分支 1 的评级。

作者观点（参考单元）：游戏市场像赢家通吃的锦标赛，输家大多看不见，看基准要看未经筛选的发行列表（p.249–250）；大细分回报高、竞争也多，两者趋于平衡（p.252–253）；未被满足的细分是最好的策略，但事前没法测量（p.254）；这些都是模型，不是现实（p.261–263）。

## A1 — 书中案例 (Past Application)

- **分支 1｜Deus Ex 与 BioShock（转述，p.256–257）**：Deus Ex 在赛博朋克阴谋、反应式剧情、黑暗氛围、哲学主题上强，潜行、射击、RPG 成长弱一些。两款叠在一起：潜行迷选 Deus Ex（系统更深、更平衡），射击迷选 BioShock；BioShock 没有赛博朋克阴谋，Deus Ex 没有 Big Daddy/Little Sister 生态和装饰艺术风世界。三张曲线图原图缺失（转换时丢失），只能依正文重建。
- **分支 2｜BioShock 与 Garry's Mod（转述，p.258–260）**：BioShock 不在拥挤的射击、潜行、剧情上硬拼，发明了别人没有的价值；它也没做 Deus Ex 那样深的反应式剧情（太贵、稀释情感纯度），1960 年的海底城也容不下赛博朋克阴谋。作者说它大获成功。Garry's Mod 一人做成，只把「古怪的创造力」推到极致，独占细分五年，卖出一百多万套。
- **分支 3｜Elemental Conflict（作者亲历，p.260–261）**：作者业余时做 Counter-Strike 的未来版，保留回合、团队、经济和武器平衡，加上火箭背包和胶水手雷，什么都没删。六人做了 14 个月，最后只有一台公开服务器，没人玩。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 立项或定位评审，要说清「我们的卖点是什么」。
2. 范围评审，要决定追哪几个特色、砍哪几个。
3. 提案写成「像 X，但加上 Y」。
4. 小团队想做大作同类型的游戏。

**语言信号**

- 和竞品比我们有什么 ／ 我们的卖点 ／ 该做哪几个特色 ／ 是不是什么都想要 ／ 像某某但更好 ／ 差异化
- value curve ／ unique selling point ／ competitor analysis ／ positioning ／ feature creep ／ scope too big

**与相邻卡的区分（初稿）**

- 商业模式或游戏目的给设计什么约束、宣传会给玩家什么预期 → `sylvester-purpose-and-expectations.md`
- 某个机制值不值得加（看理解负担和开发成本，不看竞品） → `sylvester-mechanic-cost-elegance.md`
- 核心玩法是什么、哪些放进 backlog → `sylvester-core-and-backlog.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 想看清和竞品比各有什么 | 分支 1 |
| 已有对比，要定追几项、砍哪些 | 分支 2（先过分支 1） |
| 提案是「像某成功作再加点东西」 | 分支 3（先过分支 1） |

### 分支 1：价值曲线对比（u10-06）

- **输入**：本作的体验描述；候选竞品；评级依据（设计者判断、试玩或评测）。竞品范围和评级依据由设计者定并写明理由，缺了先问。
- **步骤**：
  1. 把本作拆成一组市场价值，每项写成「哪类人想要哪种体验」（p.255–256）。完成标准：价值清单。拆多细原书未说明。
  2. 把市场上相似的游戏都拉进来，作者说最终可能有五六款（p.257）。完成标准：竞品清单及入选理由；怎样算相似原书未说明。
  3. 逐项给每款评相对高低：看它在这项价值上做得多深、多好（p.256–257）。原刻度在缺失的曲线图里，原图缺失（转换时丢失）；约定：用相对等级（如无 / 低 / 中 / 高），每格附一句理由。完成标准：每格有等级，没有的标「无」。
  4. 读出三类结果：每项价值谁提供得最好、哪些是某款独有、哪些重叠（p.257）。只画一款没有用，曲线是比较工具（p.257）。完成标准：三张清单。
- **输出**（约定）：价值 × 游戏的相对评级表，加三类读数和评级理由。

### 分支 2：价值聚焦与价值预算（u10-07）

- **输入**：分支 1 的表；团队规模与资源。
- **步骤**：
  1. 把本作的价值分三类：独有（没人提供）、优势（胜过所有竞品）、劣势（低于已有游戏）。只有前两类是卖点，劣势价值玩家在别处有更好的选择（p.258）。完成标准：每项有类别。
  2. 定追几项。作者的经验估计：大团队可以试 1 项独有、2 项优势，再加少量劣势价值补全体验；小团队可能只能专注 1 项；两人的独立游戏可能只有一两项（p.259、p.261）。大小团队的界线原书未说明，最终项数由设计者定。完成标准：建议项数，标明是经验估计。
  3. 没被选为主攻的价值，逐项写三重成本理由：耗资源；降低情感纯度，价值太多会变成一团浑浊的乱麻；与主价值不相容（p.258）。三者的权重原书未说明。完成标准：每项写明适用哪几条成本。
  4. 看形状：应是少数几根高耸的尖刺（p.260）。没有一项高过竞品 → 分支 3。
- **输出**（约定）：价值预算表，列为「价值 / 类别 / 处置（主攻 / 补全 / 砍）/ 理由与页码」。

### 分支 3：尖刺与树桩诊断（u10-08）

- **输入**：提案对标的成功作；保留了什么、加了什么、删了什么；本团队与对标作的资源对比；分支 1 的评级。
- **步骤**：
  1. 查症状：曲线又矮又宽，没有一项价值高出竞品，是大作的平庸版本（p.260）。完成标准：写明有没有高出竞品的价值、是哪项。
  2. 查成因：想做「同样的东西但更好」却没有更强的开发资源；照搬成功作、加新玩意、什么都没删（p.260–261）。完成标准：保留 / 新增 / 删除三张清单，删除为空要标出。
  3. 若判为树桩：野心与资源相称，砍掉与大作正面重叠的部分，把一项价值推到极致（p.259–261），再进分支 2 定预算。完成标准：砍除清单和要推到极致的那一项。
- **判停 / 转向**：判定依赖设计者给的相对评级，不承诺客观。
- **输出**（约定）：诊断结论、砍除清单、主推价值；下一轮再画一次对比表复查。

## B — 边界 (Boundary)

**不要用这张卡**

- 预测销量，或在大细分和小细分之间选：作者说两者趋于平衡、细分规模量不出来（p.252–253），这里没有可执行的判据。
- 只看机制本身的成本和优雅 → `sylvester-mechanic-cost-elegance.md`。

**作者警告的失败模式**

- 在别人做得更好的价值上竞争，资源均匀摊到所有特性（p.258–259）。
- 树桩：复制成功作、加新玩意、什么都没删（p.260–261）。
- 把市场模型当真相：作者提醒这类分析很容易让人过度自信（p.261）；StarCraft 在韩国的走红没人预测得到，连事后故事都可能误导（p.261–263）。

**作者盲点与时代局限**

- 「成功的小游戏几乎都是尖刺形」带幸存者偏差（p.260）。作者在 p.249–250 自己警告过这种偏差，却没用在这里。
- p.260 那张「主价值 / 次价值」小游戏表在转换时被误标成页边要点，它是表格，不是作者的要点句。
- 例子只有 PC 3A 和独立游戏；市场数据和商业模式停在 2012 年前后。

**各分支的已知缺口**

- 分支 1：三张曲线图原图缺失（转换时丢失，p.256–259），评分刻度未知；评级是主观判断，作者没给评分标准；价值拆多细、竞品怎么挑原书未说明。
- 分支 2：项数口径是作者的经验估计，未经验证；依赖分支 1 的主观评级；市场不可预测（p.261–263）。
- 分支 3：只有一个亲历案例；资源配比是作者经验。
