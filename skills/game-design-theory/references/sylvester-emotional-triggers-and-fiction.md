# 情绪触发器与虚构的取舍

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> Spectacle works when it reinforces what’s already there. … The same explosion dispensed again and again outside the context of any challenge leaves players numb.
>
> 译：奇观在强化已有的东西时才管用。……同一场爆炸脱离任何挑战一遍遍地放，只会让玩家麻木。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Emotion Through Spectacle, p.25

> The reason that crates and other such clichés appear over and over is that they cleanly justify good mechanics.
>
> 译：木箱这类陈词滥调反复出现，是因为它们能干净利落地给好机制一个说法。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Fiction Versus Mechanics, p.32

> some kinds of emotions that work individually don’t coexist easily because they’re antagonistic toward each other. … There’s a fine line between juxtaposition and antagonistic emotions.
>
> 译：有些情绪单独都行，放在一起却难以共存，因为它们彼此对抗。……并置和对抗之间只隔一条细线。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Antagonistic Emotions, p.36

## I — 方法骨架 (Interpretation)

这张卡回答「情绪该从哪里来，几种来源放在一起会不会出事」。情绪触发器（emotional trigger）指引发情绪的任何事物或观察（p.11）。作者列了学习、角色弧、挑战、社交、获取、音乐、奇观、美、环境、新技术、原始威胁、性信号等（p.19–29），其中几类来得容易，代价也在这里。机制和虚构（fiction，包在机制外的图像、声音、名字、设定）各自擅长不同的情绪，又很容易互相干扰；虚构里的俗套多半在替机制圆场（p.31–32）。情绪放在一起也不是简单相加：可以同向叠加、刻意并置，也可能互相抵消（p.34–36）。

四个分支：分支 1 逐项核查廉价触发器的代价；分支 2 把目标情绪分给机制或虚构；分支 3 列出两层的冲突，附作者的取舍考量；分支 4 查情绪组合方式。分支 2 常接分支 3，分支 1、4 按问题单独进入。

作者观点（只作参考）：虚构是加在机制情绪之上的第二层意义，玩家从不会忘记自己在玩游戏（p.30）。作者另说决策是游戏唯一独有的情绪触发器（p.120）。

## A1 — 书中案例 (Past Application)

- **分支 1｜CD-ROM 全动态视频与 Doom（转述，p.28）**：1990 年代中期 PC 能播 CD-ROM 视频后，出了一批作者称为史上最差的游戏，既不成电影也不成游戏；作者说原因不止技术崇拜，但对技术的错误信任让灾难成为可能。Doom 用任意角度的墙和光照做出新体验：拿道具时灯灭、恶魔冲进房间，黑暗里听见呻吟原地转圈。它成了大作。
- **分支 2｜原书未提供案例，以下是合成演练**：烹饪模拟的目标情绪里，「菜谱精通」「和朋友比拼」归机制（原文明列虚构做不到）；「怀旧温情」不在清单，标「原书未列」。
- **分支 3｜剧院关卡（作者亲历，p.32）**：老式剧院太开阔，试玩者一探头就被狙；在剧情和工期约束下他放了几个木箱，木箱被嘲笑，战斗成立了。**Player League（作者亲历，p.32–33）**：夜店搭讪题材的即时战略，事件全是人际情绪，画面上只是一群人在说话；改用彩色线条表示关系，勉强能用但要死记，作者自述这个游戏没做成。
- **分支 4｜（转述，p.35–37）**：街机把快节奏音乐、高风险局面、暴力题材、竞争叠到任何单个达不到的兴奋；Gears of War 在暴力表层下藏着哀悼（作者亲历），并置让它不只是血浆秀；作者朋友玩射击，主要角色死亡的过场刚结束，主角捡弹药喊「Sweet!」，朋友笑出声；LIMBO、DEFCON、Flower 用音乐和慢节奏交互造氛围，再用不同虚构定调。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 方案靠大场面、精美美术、新技术或血腥惊吓撑情绪。
2. 不确定某种目标情绪该交给玩法还是剧情。
3. 设定和机制打架：为了平衡要加看着别扭的道具，或设定不允许改某条规则。
4. 想在现有体验里加一种新情绪（竞技排行、悲剧桥段），怕串味。

**语言信号**

- 加点特效 ／ 画面再精美点 ／ 首款用某技术 ／ 恐怖靠血腥够不够 ／ 这种情绪靠玩法还是靠剧情 ／ 设定不让改 ／ 关卡里的箱子很假 ／ 两种情绪互相抵消
- spectacle ／ eye candy ／ tech showcase ／ gore ／ fiction vs mechanics ／ ludonarrative ／ crates ／ cliche ／ juxtaposition ／ tonal clash ／ atmosphere

**与相邻卡的区分（初稿）**

- 美术让玩家看不懂机制、视觉线索前后不一 → `sylvester-mechanic-metaphor.md`
- 给机制或系统限制找虚构理由；环境讲故事 → `sylvester-world-narrative.md`
- 玩家做出角色不会做的事 → `sylvester-desk-jumping-and-characters.md`
- 情绪曲线、沉浸 → `sylvester-intensity-and-immersion.md`
- 事件本身为何没情绪 → `sylvester-experience-analysis.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 想用奇观、美、新技术、原始威胁、性信号提情绪 | 分支 1 |
| 某种目标情绪该交给机制还是虚构 | 分支 2 |
| 设定和机制打架、俗套刺眼、核心事件表达不出来 | 分支 3 |
| 几种情绪放在一起，怕互相抵消；想确认氛围 | 分支 4 |

### 分支 1：廉价触发器代价核查

- **输入**：用到的奇观、美术方向、技术卖点、恐怖手段、性信号；题材；目标受众。受众不明先问，第 5 项要用。
- **步骤**：逐项判「不适用 / 通过 / 风险」，附理由。
  1. 奇观：是否强化玩家已有的情绪（苦战获胜后的爆炸）；是否脱离挑战反复投放（p.25）。
  2. 美：是否与题材冲突（抑郁、恐怖、不安）；是否增加视听噪声、让游戏更难懂；是否服务一个具体目的（p.26）。
  3. 新技术：能否说出它解锁了哪些以前体验不到的交互和情境，而不只是技术演示（p.27–28）。
  4. 原始威胁：是否只靠血腥、蜘蛛这类现成刺激（p.28–29）。
  5. 性信号：是否损害严肃叙事的氛围和可信度、是否惹恼不感兴趣的受众；严肃或面向大众的游戏通常不值得（p.29）。
- **判停 / 转向**：「更深层的威胁」怎么做原书未说明；美的目的是否成立、受众能否接受，由设计者判断。美术噪声细查 → `sylvester-mechanic-metaphor.md`（第 9 章 p.225）。
- **输出**（约定）：五行表，列为「项目 / 判定 / 作者的问题 / 理由」。

### 分支 2：情绪交给机制还是虚构

- **输入**：目标情绪清单，用比 fun 更具体的词（p.10）。
- **步骤**：逐个情绪对照 p.31 的清单，保留原文的强度措辞。
  1. 机制擅长：紧张、释然、胜利、失败、学习的乐趣、解谜的骄傲、与真人的社交。
  2. 纯机制难做（hard）：幽默、敬畏、沉浸；没有角色，经由共情的整片情绪几乎做不到（almost inaccessible）。
  3. 虚构能做：角色、情节、世界带来的笑与泪、震惊、着迷；做不到（can't）：竞争、胜负、技能掌握、与真人社交。
  4. 写出每个情绪主要靠哪一层，两层结合可以兼取两边（p.31）。完成标准：每个情绪一行。
- **判停 / 转向**：清单外的情绪标「原书未列」，交设计者。两层都要用 → 分支 3。
- **输出**（约定）：表，列为「目标情绪 / 主要承担层 / 原文措辞」。

### 分支 3：虚构与机制冲突

- **输入**：虚构设定（题材、世界、角色）；机制清单；已知的试玩问题。
- **步骤**：
  1. 列出虚构里的俗套和别扭约束，逐个问它在替哪条机制圆场：木箱挡狙击视线；失忆主角让别人讲常识；超级士兵对应成百上千的短命敌人；没有恐惧和悔意的敌人对应可预测（p.32）。完成标准：每项写出对应机制，找不到的标出。
  2. 列出因虚构而做不了的机制修改，如写实题材不能降重力、不能让火不烧某些角色（p.33）。
  3. 查核心事件能否被表现层清楚表达；Player League 失败的主因就是表达不出来（p.32–33）。
  4. 每处冲突列出作者的考量，由设计者定偏机制、偏虚构还是寻求整合：偏机制可得平衡、清晰、有深度的挑战，但难找贴合的虚构；偏虚构则只能做不违背虚构的机制修改（p.33）；剧情和工期约束下没有简单答案（p.32）；两者合成一个意义系统是工艺的巅峰（p.34）。
- **判停 / 转向**：整合的具体手段本节没给。第 4 章说要让玩家和角色想要同一件事，就得把虚构和机制当一个整体设计（p.106）→ `sylvester-desk-jumping-and-characters.md`；虚构让玩家误判有哪些交互（第 5 章 p.135–136）→ `sylvester-fiction-and-metagame-info.md`。
- **输出**（约定）：冲突清单（圆场项 / 被锁住的修改 / 表达不清的核心事件），每项附考量和「设计者决定」一栏。

### 分支 4：情绪组合方式

- **输入**：目标体验；现有或拟加的情绪来源。
- **步骤**：
  1. 叠加：为一个目标情绪列出所有指向它的触发器，查是否同向（p.35）。
  2. 并置：标出刻意放在一起、看似不相容的情绪及其意图（p.35）。
  3. 对抗：排查会互相抵消的组合，至少查作者点名的「一起玩的社交乐趣 vs 残酷的技能竞争」（p.36）。
  4. 氛围：在游戏里停下来什么都不做，感受一分钟，记下背景情绪（p.36）。
- **判停 / 转向**：并置会成还是互相抵消，原书没有判据，结果可能出乎意料（p.36）：标风险，交试玩。作者给的低成本实验是把配乐换成情绪相反的曲子，看效果（p.35–36）；作者还观察到朋友玩技能游戏常约定「只是玩玩」，调低竞争强度给社交让位（p.36）。不替设计者选组合方式。
- **输出**（约定）：表，列为「组合 / 涉及的情绪与触发器 / 叠加、并置或疑似对抗 / 风险与理由」，附氛围记录。

## B — 边界 (Boundary)

**不要用这张卡**

- 判断性信号、血腥内容是否得体：「tasteless」「某类受众」是价值判断，作者说本书讲工艺不讲伦理（p.218）。
- 定游戏的目的：设计工艺不决定游戏目的，只告诉你怎么达成（p.5）→ `sylvester-purpose-and-expectations.md`。

**作者警告的失败模式**

- 奇观被钱多、创意少的工作室滥用，挤掉更深的情绪来源（p.25）；条件反射地往每个场景堆美（p.26）。
- 新技术本身当卖点，几年后就不好看了（p.27–28）；血腥和蜘蛛被滥用几十年，很多人自动忽略甚至笑出来（p.28–29）。
- 虚构定死之后才暴露机制问题，只能用俗套硬补；选了核心事件表达不出来的题材（p.32–33）。
- 想并置，结果两种情绪互相湮灭（p.36）。

**作者盲点与时代局限**

- 五类代价是作者自己串起来的，都是品味判断，没有数据；新技术一条写于 2012 年前后。
- 机制、虚构各擅长什么，是作者的断言清单，未经论证；氛围游戏用音乐和慢节奏交互做情绪（p.36–37），不完全落在两层二分里。

**各分支的已知缺口**

- 分支 1：「更深层的威胁」没有做法。
- 分支 2：只覆盖作者列出的情绪。
- 分支 3：作者的例子来自射击关卡与即时战略原型（亲历）；没有取舍判据，整合手段本节没有，叙事章可能另有。
- 分支 4：对抗情绪只有一个点名组合；并置与对抗之间没有判据（p.36）；「一分钟」是随口的建议，不是阈值。
