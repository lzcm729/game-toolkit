# 难度与失败

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> Flow appears when a player is presented with a challenge that is perfectly balanced against his ability level. If the task is too hard, flow breaks as the player becomes confused and anxious. If it is too easy, the player gets bored.
>
> 译：挑战与玩家能力恰好相当时，心流就出现了。任务太难，玩家困惑、焦虑，心流断掉；太容易，玩家就无聊。
>
> — Tynan Sylvester, *Designing Games*, Ch1 Engines of Experience / Flow, p.39

> A pass/fail design only serves players who are just barely good enough to pass the challenge.
>
> 译：只分过关和失败的设计，只服务那些刚好够格过关的玩家。
>
> — Tynan Sylvester, *Designing Games*, Ch3 Skill / Elastic Challenges, p.72

> Do not punish the player himself for failure. Find other ways to create suspense.
>
> 译：不要为失败惩罚玩家本人。另找办法制造悬念。
>
> — Tynan Sylvester, *Designing Games*, Ch3 Skill / Handling Failure, p.78

## I — 方法骨架 (Interpretation)

这张卡回答「太难、太易、失败太伤人、玩家卡死」。挑战与能力相当时才有心流（flow，全神投入的状态），而合适的难度区因人而异（p.63），所以难度问题先要按玩家分组看。失败又是悬念必需的：要有在乎的东西悬在半空，失败的可能必须真实（p.78），难点在于罚谁、怎么罚。

分支 1 找心流中断点，是诊断入口。修法有两种：分支 2 让同一个挑战有多档成败，服务更宽的技能段；分支 3 把整体难度平移。失败本身的问题走分支 4（失败后玩家要经历什么）和分支 5（长时间锁在必败局面）。分支 5 的解法里会用到分支 2 的弹性失败和分支 3 的暗调难度。

## A1 — 书中案例 (Past Application)

- **分支 1｜Heroes III（作者亲历，p.39）**：作者晚上七点要到部队集合，五点看钟还早，再抬头已是 6:37，只好一路狂奔；他用这件事说明心流让时间消失。原书未提供中断排查的案例。
- **分支 2｜飞镖与 Hitman（例题 + 转述，p.71–73）**：只有一英寸靶心的飞镖几乎只有高手能玩，真飞镖套上分环，人人有够得着又有挑战的目标；街机投币按键就有几千分，高手能刷到上亿。Hitman 杀目标很容易，拿 Silent Assassin 评级要无目击、无多余暴力，中间有一整串评级。失败也能分档：没跳过沟就抓住崖边慢慢爬上来；AI 队友倒地可救，付出时间和资源。
- **分支 3｜RE5、TF2、CoD4（转述，p.77–78）**：Resident Evil 5 有四个显式档，内部 1–10 级自适应，简单档在 1–4 间暗调、普通档在 3–7 间，另有锁死 10 级的模式给高手。Team Fortress 2 的狙击手要精准瞄准，工程师和医疗兵不用瞄，玩家按技能自己分流。CoD4 的刷怪触发器让猛冲的高手同时面对几批敌人，谨慎的新手一批批清。
- **分支 4｜StarCraft II 战役、Super Meat Boy、Dwarf Fortress（转述，p.79）**：进攻失败只损失部分兵力，可以重建再攻；Meat Boy 一秒内复活，死一百次心流也不断；要塞崩溃本身就好看，游戏一直往新局面走。
- **分支 5｜各类 failure trap（转述，p.79–80）**：体育比赛大比分落后的「行尸走肉」，半小时很折磨；赛车落后太远追不上；线性游戏卡在一个挑战上反复撞墙；射击游戏没弹药时碰到存档点，反复从那里重来。Super Meat Boy 每个世界 20 关，过 18 关即可前进。作者说赛车和体育的这类陷阱至今没人彻底解决。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 试玩反馈「太难」「太简单」，或新手和老手的反馈互相矛盾。
2. 要定难度档、动态难度或要不要难度选择。
3. 死亡、失败后要读档、重打、刷回损失，玩家烦了。
4. 玩家卡在一关、一个存档、一局大比分落后里出不来。

**语言信号**

- 太难 ／ 太简单 ／ 难度怎么调 ／ 要不要做难度选择 ／ 动态难度 ／ 失败惩罚太重 ／ 死了重来太久 ／ 卡关 ／ 必败局面 ／ 要不要加投降
- difficulty ／ adaptive difficulty ／ difficulty settings ／ death penalty ／ checkpoint ／ pass/fail ／ failure trap ／ stuck

**与相邻卡的区分（初稿）**

- 区间要不要宽、该用哪类手段 → `sylvester-skill-range.md`；教程 → `sylvester-onboarding-and-opening.md`
- 冷却、过场、决策太密等与难度无关的断流（第 5 章）→ `sylvester-pacing-problems.md`
- 比赛早早定局没悬念 → `sylvester-suspense-and-insight.md`；失败和损失处缺奖励期待 → `sylvester-reward-schedule-diagnosis.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 不知道哪段太难或太易 | 分支 1 |
| 一个挑战只有过或不过，新手过不了、高手没挑战 | 分支 2 |
| 整体难度对不上，要定难度系统 | 分支 3 |
| 失败后的惩罚伤人 | 分支 4 |
| 玩家长时间被锁在必败局面 | 分支 5 |

### 分支 1：心流中断排查（u01-21）

- **输入**：逐段的试玩观察或预计；玩家技能分组。缺观察先问，不替玩家编症状。
- **步骤**：
  1. 逐段对照挑战与玩家能力（p.39）。
  2. 出现困惑、焦虑的段标「过难」，无聊的标「过易」（p.39）。
  3. 按技能组分别标，合适的难度区因人而异（p.63）。完成标准：每组一份中断点清单。
  4. 中断点交给分支 2、3，或先到 `sylvester-skill-range.md` 分支 4 选手段（p.63）。
- **判停 / 转向**：原书只给症状，没有测量挑战量的方法。断流不止难度一个原因，加载等打断也会断（Super Meat Boy 正因复活快而心流不断，p.79），决策注入速率见第 5 章 → `sylvester-pacing-problems.md`。
- **输出**（约定）：「段落 / 技能组 / 过难或过易 / 观察到的症状」表。

### 分支 2：弹性挑战（u03-07）

- **输入**：只有过关 / 失败两种结果的挑战；目标技能组。
- **步骤**：
  1. 找出只分过关和失败的挑战（p.72）。
  2. 向上加分档成功：细分计分（飞镖分环、街机分数）或评级谱（Hitman）（p.71–72）。
  3. 向下加分档失败：进度放慢但游戏继续（抓崖边）；队友倒地可救，付出时间和资源（p.73）。
  4. 检查每个目标技能组都有一档够得着又有挑战（p.72–73）。完成标准：每组对得上一档。
- **判停 / 转向**：分几档、门槛放哪，原书没给，由设计者和试玩定。向下延展时保住失败的真实可能（p.78）。
- **输出**（约定）：成败谱，列为「档位 / 条件 / 面向的技能组」。

### 分支 3：难度调整选型（u03-10）

- **输入**：会不会有玩家练到很高技能；是不是竞技多人；受众是否混合。缺了先问。
- **步骤**：
  1. 显式选择：好做、还算有效；难处是选择本身让人困惑。缓解：首关测试后推荐、用例子描述各档、允许中途改（p.76）。
  2. 自适应：暗中按表现调（下个房间放食物、派盟友、调秘密难度计数）；玩家不知道时效果最好；只适合不期待玩家练到很高技能的游戏，高手会摸清并操纵它（p.76）。
  3. 隐式：让难易不同的策略明显可见，玩家自己选；能用于竞技多人，显式选择不能（p.77）。
  4. 组合：显式档框住自适应区间，另设锁死最高内部难度的模式（RE5 的数字只是例子，p.77）。
  5. 按作者给的条件筛：有高手 → 不用单纯自适应，或加锁死模式；竞技多人 → 隐式。完成标准：每个选择写明依据的条件。
- **判停 / 转向**：受众混合时只有 RE5 一例可参照，不承诺最优选择。
- **输出**（约定）：「方式 / 适用条件 / 缓解办法 / 本作是否采用」表。

### 分支 4：失败惩罚改造（u03-11）

- **输入**：每种失败及失败后玩家要经历的事。
- **步骤**：
  1. 列出每种失败之后玩家要经历什么（p.78）。
  2. 标出惩罚玩家本人的部分：等加载、反复重玩同一段、无脑刷资源补损失（p.78）。
  3. 改为惩罚角色（中枪、离婚、破产……），靠有力的角色塑造让后果有分量（p.78）；不够时拒绝成功或给小挫折：损失些资源或盟友、错过一小段叙事或信息，游戏沿新路继续（p.79）。
  4. 两项检查：失败威胁仍可信（p.78）；玩法没有塌缩成重复（p.79）。完成标准：每种失败过两项。
- **判停 / 转向**：重玩不一定坏，Super Meat Boy 秒复活是正例（p.79）。悬念够不够要试玩判断。
- **输出**（约定）：「失败 / 后果 / 罚玩家、罚角色或小挫折 / 替代方案 / 两项检查」表。

### 分支 5：Failure trap 排查（u03-12）

- **输入**：比分、进度、存档或复活点、可耗尽资源的规则。
- **步骤**：
  1. 找玩家会长时间锁在必败局面的情况：比分悬殊、竞速落后太远、线性卡关（p.79–80）。
  2. 重点查机制组合涌现的那类，如没弹药时触发存档点（p.80）。把「可耗尽资源 × 存档点」推广成排查方向是本卡的重建，原书只有这一例。
  3. 按成因逐个定制解法，作者的菜单（p.80）：弹性失败条件（弱的无限弹药备用武器、最低回血线）；提前结束（投降）；提示；暗中调难度；替代挑战（20 关过 18 关即可前进）。
  4. 解决不了的标出来（p.80）。完成标准：每个陷阱有成因，以及解法或「无解」。
- **判停 / 转向**：作者明说没有单一解法，成因到解法没有对应规则；「长时间」没有阈值，「半小时」只是体育例的描述。
- **输出**（约定）：「陷阱 / 成因 / 候选解法 / 无解标注」表。

## B — 边界 (Boundary)

**不要用这张卡**

- 定区间宽窄、门槛和天花板 → `sylvester-skill-range.md`。
- 断流来自等待、过场或决策太密 → `sylvester-pacing-problems.md`。

**作者警告的失败模式**

- 把体验问题归到剧情、美术，没发现是心流断了；心流一断，体验其他部分都垮（p.40）。
- 显式难度选项让人担心选错（p.76）；自适应被察觉后，玩家会钻空子，或把每个随机事件都归到它头上、觉得体验是假的（p.76）。
- 惩罚玩家本人；作者说这在别处没人会故意设计，失败后却被奇怪地接受（p.78）。
- 涌现型 failure trap 最危险，也最难预料（p.80）。
- 成败谱向下延展过头：作者要求失败的可能必须真实（p.78），否则悬念变弱。
- 反过来，重玩不总是坏事：Super Meat Boy 的秒复活是作者的正例（p.79）。

**跨章条件**

- 第 5 章：心流可看成决策注入速率；成品里被决策淹没的多是技能较低的玩家，作者主张刻意选定最低技能水平（p.144），见 `sylvester-pacing-problems.md`。
- 第 12 章：埋点数据能看出难度和节奏的细小变化，供细调（p.317），见 `sylvester-metrics-and-telemetry.md`。

**作者盲点与时代局限**

- 自适应难度、暗中调难度都按「玩家察觉不到」当优点讲，没讨论知情与公平（批判节）。
- RE5 的档位数字只是例子；「半小时」是体育例的描述，不是阈值；例子偏单机动作与策略。
- 心流图原图缺失（转换时丢失），两个失败方向正文已写明。

**各分支的已知缺口**

- 分支 1：没有挑战量的测量方法。
- 分支 2：分几档、档间距原书未说明。
- 分支 3：受众混合时只有一例。
- 分支 4：多少重复算塌缩、角色塑造不足时怎么办，原书未说明。
- 分支 5：怎样系统找出没想到的涌现陷阱，原书未说明。
