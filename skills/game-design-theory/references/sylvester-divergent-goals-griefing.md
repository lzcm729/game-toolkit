# 分歧目标与 griefing：有人不按目标玩、有人捣乱

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> There is a divergent goal, but it’s still aligned closely enough with the official goal that the game mostly works.
>
> 译：分歧目标是有的，但它和官方目标还算对得上，所以游戏大体还能运转。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Divergent Goals, p.198

> For a game to work online, designers must identify the most severe griefing strategies and solve those. Below a certain cutoff of severity, it isn’t worth twisting the core game to disallow griefing.
>
> 译：游戏要在线上跑得起来，设计者得找出最严重的那几种 griefing 并解决掉。严重度低于某条线的，不值得为禁止它去扭曲核心玩法。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Divergent Goals, p.200

> A multiplayer design needs to be robust enough to handle the constant low-grade chaos caused by players dropping out, griefing, missing key skills, or deciding to play wrong.
>
> 译：多人设计要够结实，扛得住持续不断的低烈度混乱：有人掉线，有人捣乱，有人缺关键技能，有人偏不按设计玩。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Skill Differentials, p.202

## I — 方法骨架 (Interpretation)

这张卡回答「多人里有人不推目标、有人捣乱、有人中途走，设计怎么扛」。作者把破坏性行为分两类：分歧目标（divergent goals）和技能差；技能差去 `sylvester-skill-gap-interdependence.md`。分歧目标是玩家去追会弄坏别人体验的目标。单人里玩家不按设计意图玩通常不致命，多人里每个人的目标都影响所有人（p.197）。分歧目标常是游戏自己造出来的：它另外记录或奖励了某样东西。伤害大小看它和官方目标对得多齐。griefing 是最坏的一类：为了自己好玩，故意毁掉别人的体验（p.199）。面对面的游戏有友情和挨揍的威胁约束，线上匿名、随时能走，只能靠设计本身（p.199）。

分支 1 从已看到的行为进入，归类并评估对齐；分支 2 按作者给的防线顺序处置，从第一道到最后一道；分支 3 在上线前用四种扰动做压力测试，不成立的项分给分支 1、2 或技能差卡。

## A1 — 书中案例 (Past Application)

- **分支 1｜击杀统计与独行（转述，p.198–199）**：Modern Warfare 夺旗赛的官方目标是多夺旗，但游戏把每人的击杀数存进永久数据库，杀人又比看角落的比分更爽，于是有人只刷人头。设计没散架，只因杀敌通常仍帮团队；作者的判断是受了伤、没被毁。Left 4 Dead 是四人互助求生，有人独自跑开看自己能走多远，队友没了支援，精心平衡的游戏崩了。离开游戏本身也是一种分歧目标。
- **分支 2｜防线实例（转述 + 例题，p.199–201）**：griefing 有卡门口、打盟友、WoW 里在队友跳水时给他施水上行走、CS 用喷图在要道喷骇人图片。L4D 一局四人、45 分钟，有人离开 AI 立刻接管，作者说不如真人但能凑合。最严重的做成不可能：射击允许穿过队友防卡门，MMO 城镇设怪物不进的安全区。阈值以下的：策略游戏躲着不打，griefer 不好玩，对方白捡一场胜利；射击里自杀也能坑队友，但死不好玩，没人这么干。
- **分支 3｜内部试玩骗过了团队（作者转述的采访，Ch11, p.296）**：一款失败的多人射击游戏，团队坐在一个房间里边吃边玩、反复打磨，深度和平衡都好；上线后被网上的陌生人玩，它太依赖精细的团队战术，崩了，在市场和多数玩家那里都失败了。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 个人战绩、排行榜让玩家不推团队目标。
2. 试玩或上线后有人堵路、坑队友、恶意干扰。
3. 有人中途掉线或退出，剩下的人玩不下去。
4. 多人模式定稿前，想确认它经得起真实玩家。
5. 讨论要不要做举报、投票踢人、管理员。

**语言信号**

- 刷数据不推目标 ／ 有人捣乱 ／ 坑队友 ／ 掉线怎么办 ／ 中途退出 ／ 不按设计玩 ／ 要不要做举报
- griefing ／ trolling ／ divergent goals ／ stat padding ／ leavers ／ AFK ／ vote kick ／ moderation

**与相邻卡的区分（初稿）**

- 新手拖累、高手虐新手、一人失误全队受罚 → `sylvester-skill-gap-interdependence.md`
- 单人里奖励把玩家引离他本来想做的事 → `sylvester-reward-alignment.md`
- 单人里玩家做角色不会做的事（desk jumping）→ `sylvester-desk-jumping-and-characters.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 已经看到有人刷数据、捣乱、退出，想知道问题在哪 | 分支 1 |
| 已知要处理哪些行为，想定对策 | 分支 2 |
| 多人设计还没上线，想先查扛不扛得住 | 分支 3 |

### 分支 1：分歧目标排查与对齐评估（u07-10）

- **输入**：观察到的行为；各模式的官方胜利条件；游戏记录、存档、展示或奖励的个人数据。缺了先问。
- **步骤**：
  1. 归类：分歧目标还是技能差（p.198）。技能差转 `sylvester-skill-gap-interdependence.md`。完成标准：每个行为一个归类。
  2. 写出官方目标，比如夺旗赛是时间到时夺旗比对方多（p.198）。
  3. 列分歧目标的来源：游戏另外追踪、永久存档或奖励的东西（击杀数）；比官方目标更直接爽的事（杀人、独自挑战）；离开去干别的（p.198–199）。这三类是从作者的例子归纳的，不是他给的清单。完成标准：每个分歧目标写来源。
  4. 评估对齐：追它仍有助于官方目标（击杀帮团队，大体能运转），还是完全反着来（独行，游戏崩）（p.198）。完成标准：每项标「同向 / 部分同向 / 相反」并写理由；原文只给两端，中间程度由设计者判断。
  5. 以惹恼别人为乐的单列为 griefing（p.199），与相反、部分同向的一起交分支 2。
- **输出**（约定）：表「行为 / 分歧目标 / 来源 / 对齐 / 理由」。

### 分支 2：分层防线（u07-11）

- **输入**：分支 1 或分支 3 交来的行为清单；队伍人数；有没有 policing 的预算。
- **步骤**（顺序是作者给的）：
  1. 第一道防线，让目标合理：玩家想征服、探索、交流、影响他人，若做到这些的最好办法就是照设计玩，他们就会照设计玩（p.199）。具体做法原文指回第 4 章的 desk jumping。完成标准：每个分歧目标写一条动机层改法，或写「改不了」。
  2. 承认让所有人目标一致几乎不可能，再上其他措施（p.199）。
  3. 人数缓冲：一个人胡闹、退出、捣乱，在两人队里比在 12 人队里要紧得多（p.200）。完成标准：写明人数能缓冲哪些项。
  4. 针对性方案：具体问题具体解，例如有人离开就由 AI 接管（p.200）。
  5. griefing 按两维分级：对 griefer 有多好玩 × 对他人破坏多大（p.200）。很好玩又毁局的做成不可能；不好玩或不伤人的在阈值以下，不为禁它去扭曲核心玩法（p.200）。禁不完，总有办法恶心人，哪怕是故意输（p.200）。完成标准：每项有两维评级和处置层；阈值由设计者定，以作者的例子作锚点。
  6. 从内部防不住的，加 policing 兜底（投票、管理员）。作者说它混乱、不优雅，投票要玩家停下来自己管，管理员要花钱，但能救命（p.201）。
- **输出**（约定）：处置表「行为 / griefer 乐趣 / 对他人破坏 / 处置层（动机对齐·人数缓冲·针对方案·做成不可能·放着·policing）/ 页码」。

### 分支 3：多人鲁棒性压力测试（u07-14）

- **输入**：一个多人模式或遭遇的设计。
- **步骤**：
  1. 不假设玩家是真心合作、技能匹配的队伍：这种队伍在野外很少，假设它们存在的游戏会崩（p.202）。
  2. 对每个模式或遭遇逐项假设：有人掉线、有人捣乱、有人缺关键技能、有人不按设计玩（p.202）。
  3. 逐项判断体验能否扛住这种低烈度混乱（p.202）。完成标准：每格「成立 / 不成立」加一句理由；「成立」的标准原文没给，由设计者判断。
  4. 不成立的转对策（路由由本章前几节推出）：掉线 → 分支 2 第 3、4 步；捣乱 → 分支 2；缺技能 → `sylvester-skill-gap-interdependence.md`；乱玩 → 分支 1。
- **输出**（约定）：表「模式或遭遇 × 四种扰动 × 成立与否 × 转向」。

## B — 边界 (Boundary)

**不要用这张卡**

- 技能悬殊引起的冲突 → `sylvester-skill-gap-interdependence.md`。
- 只加举报和惩罚就算处理完：作者把 policing 放在最后一道（p.201）。

**作者警告的失败模式**

- 游戏里有比官方目标更即时、更爽、被永久记录的指标，玩家转去追它（p.198）。
- 沿用面对面游戏的假设，以为没人会故意破坏别人的体验（p.199）。
- 为每种骚扰都加禁令，把核心玩法扭曲；或最严重的几种没优先处理（p.200）。
- 设计默认玩家会配合，真实环境里散架（p.202；Ch11 的射击游戏，p.296）。

**作者盲点与时代局限**

- 作者认为线上匿名没有社会约束（p.199），没考虑持久账号、信誉、举报、匹配（批判节），要按今天的平台条件重估。
- 诱因只讨论了持久统计，通行证、战令任务等商业化奖励不在视野里。
- 例子只有 MW 与 L4D 一正一反。
- 严重度阈值、「成立」的标准原文都没给；四种扰动是作者的收尾概括，不是穷尽清单；压力测试是纸面推演还是实测，原文没说。
