# 不下指令地引导玩家

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> INDIRECT CONTROL methods can guide player behavior without the player realizing that they’re being guided. … NUDGING is changing player behavior by changing how choices are presented, without changing the choices themselves.
>
> 译：间接控制的方法能引导玩家的行为，而玩家意识不到自己被引导。……推动（nudging），是只改选择的呈现方式、不改选择本身，从而改变玩家的行为。
>
> — Tynan Sylvester, *Designing Games*, Ch9 Interface / Indirect Control; Nudging, p.232

> Priming is powerful, but it’s not magical. It doesn’t fabricate motivation from nothing. All it does is shift preferences between already-available options.
>
> 译：启动效应很有力，但不是魔法。它不能凭空造出动机，只是在已有的选项之间挪动偏好。
>
> — Tynan Sylvester, *Designing Games*, Ch9 Interface / Priming, p.234

> All we have to do is make the NPC do something that the player should also do, and players will tend to follow.
>
> 译：我们只需让 NPC 去做玩家也该做的事，玩家就会倾向于跟着做。
>
> — Tynan Sylvester, *Designing Games*, Ch9 Interface / Social Imitation, p.235

## I — 方法骨架 (Interpretation)

这张卡回答「想让玩家走某条路、选某个选项、学会某个做法，但不想弹提示、下命令或禁用别的操作」。作者把这类方法叫间接控制：不是潜意识广告之类的花招，而是安排信息，让行为自然流向预期方向（p.232）。三种手段按你能动的东西来分：

- 推动（nudging）动选择点的呈现，依据是玩家走阻力最小的路、选默认项；
- 启动（priming）动玩家进入场景前几分钟脑子里被激活的概念；
- 社会模仿（social imitation）让别人先做给玩家看，依据是人的知识多半二手学来。

三者可以叠用。共同前提是期望的做法本来就是玩家能选的：推动不限制选项、不改激励，启动不造动机。期望的做法不存在，这张卡帮不了。

## A1 — 书中案例 (Past Application)

- **分支 1｜默认项与灯光（例题，p.232）**：对话系统把默认选项设成通往最有趣结果的那个；亮着的门比暗的更吸引人，地上的线暗示路径，闪烁的按钮让人想按。原书未说明结果。
- **分支 2｜启动研究（转述，p.233）**：做过含粗鲁词测试的人 63% 打断了管理员的谈话，礼貌组只有 17%；读过「皱纹、宾果、佛罗里达」的人离开时走得更慢；被要求避免写性别歧视语句的人反而写得更多。**见线人（例题，p.234）**：此前全是战斗，很多玩家会见线人就开枪；作者不主张下令别开枪或禁用射击，改为让主角放低枪（仍可用）、让玩家先看到别人在交谈、同伴说「让我来谈」。这是假设情境，原书没有实测结果。
- **分支 3｜赛车与同伴（例题，p.235）**：电脑车过弯前减速，玩家会学着减速；经济模拟显示对手的持仓，玩家发现自己差得太多，就会意识到要么犯了错，要么在走奇招；同伴跑向下一个目标、操作谜题、躲避危险，玩家会不自觉地跟着做。原书未说明结果。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 岔路、对话或关卡里希望玩家多选某个选项，其他选项仍要保留。
2. 剧情转折处玩家的惯性不对（一路打过来，见到该交谈的角色就开枪）。
3. 想不用教程文字教会玩家某个做法，或让同伴带路。
4. 有人提议写「不要……」的提示，或临时禁用某个操作。

**语言信号**

- 想让玩家走这边但不想强制 ／ 不想弹提示 ／ 怎么暗示玩家 ／ 玩家总打不该打的 NPC ／ 不用教程怎么教 ／ 同伴怎么带路
- guide players without telling them ／ indirect control ／ nudge ／ priming ／ lead the player ／ companion guidance ／ subtle guidance

**与相邻卡的区分（初稿）**

- 可以明说，只是怕玩家漏看 → `sylvester-signal-visibility.md` 分支 4
- 想改的是奖励和激励 → `sylvester-reward-alignment.md`
- 玩家缺的是做决策的信息 → `sylvester-information-balance.md`
- 输入辅助也被作者说成悄悄「推一下」玩家的输入，那是操控层 → `sylvester-controls-feel.md` 分支 3

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 某个选择点希望玩家倾向某个选项 | 分支 1 |
| 进入某个场景前，玩家的行为惯性不对 | 分支 2 |
| 要教会玩家一个做法，或带他去某处 | 分支 3 |

三支可以叠用；用之前都先确认期望的做法是现成选项。

### 分支 1：推动（u09-09）

- **输入**：选择点；期望的选项；全部选项。
- **步骤**：
  1. 确认只动呈现：选项不删、激励不改（p.232）。要删选项或改奖励就不是推动。完成标准：书面确认。
  2. 过一遍手段（p.232）：把默认项设为通往期望体验的那个；重排选项；视觉上点亮期望方向、在地面画线指路、让该按的按钮闪烁。依据是玩家走阻力最小的路、选默认项、走最显眼的路线。完成标准：每种手段写明用或不用。
  3. 作者认为推动便宜，几乎没有理由不在每个机会都用（p.232）：把关卡或界面里的选择点逐个过一遍。完成标准：每个选择点有推动方案，或写明不用。
- **判停 / 转向**：什么时候不该推动、推动的效果有多强，原文都没说；玩家不知情的问题见 B 段。
- **输出**（约定）：表，列为「选择点 / 期望选项 / 手段 / 选项或激励是否改动（应为否）」。

### 分支 2：启动（u09-10）

- **输入**：场景；期望行为；玩家进场前几分钟经历了什么。
- **步骤**：
  1. 找出当前被启动的概念：来自前面的游玩（一路战斗＝暴力），也来自开玩前的标题、封面、别人的评价（p.234）。完成标准：概念及来源。
  2. 查前提：期望行为必须是现成选项，启动只在已有选项之间挪偏好（p.234）。不是现成选项就停，这一支不适用。完成标准：是 / 否。
  3. 不下「不要 X」的指令，也不禁用 X：两者笨拙、不优雅（p.234），而且叫人避免某事本身就在启动它（p.233）。完成标准：方案里没有禁令和禁用。
  4. 在进场前几分钟放入启动目标概念的元素：每个印象都会影响之后几分钟的选择（p.233–234）。手段如主角放低武器但仍可用、让玩家先看到别人在做期望的事、同伴的一句台词，可任意组合（p.234）。完成标准：元素清单，各有位置和时机。
- **判停 / 转向**：本分支不承诺效果大小和持续多久。「几分钟」来自作者转述的心理学实验，没有游戏内实证；放几个元素、提前多久放，原书未说明。做完用试玩核对（约定）。
- **输出**（约定）：表，列为「场景 / 当前被启动的概念 / 期望行为是否现成 / 启动元素 / 位置与时机 / 保留的操作」。

### 分支 3：社会模仿（u09-11）

- **输入**：玩家该学会的做法；能当示范者的角色或数据（NPC、同伴、AI 对手、对手的状态）。
- **步骤**：
  1. 选示范者：单人里是 NPC；多人里玩家会互相模仿策略（p.235），但多人怎么主动利用，原文没说。完成标准：示范者。
  2. 让示范者在玩家看得到的地方做玩家该做的事（p.235）：AI 车过弯前减速；显示对手的持仓供玩家对照；同伴跑向下一个目标、操作谜题、躲避危险、使用某个能力。完成标准：写明谁、做什么、在哪、什么时候被玩家看到。
- **判停 / 转向**：本分支只交示范计划，不承诺玩家一定会模仿：原文说的是玩家「倾向于」跟着做（p.235）。示范没起作用、或玩家模仿了错的做法怎么办，原书未说明，靠试玩发现。
- **输出**（约定）：表，列为「示范者 / 示范的做法 / 玩家看到的位置 / 时机」。

## B — 边界 (Boundary)

**不要用这张卡**

- 期望的做法不是玩家现成能选的：间接控制不造动机（p.234）。
- 信息必须送到、明说也没关系 → `sylvester-signal-visibility.md`。

**作者警告的失败模式**

- 用直接指令或禁用来阻止某种行为：笨拙、不优雅（p.234），禁令还会启动被禁的念头（p.233）。

**作者盲点与时代局限**

- 「玩家察觉不到」被当成优点讲（p.232、p.235），知情与操纵的问题没讨论（批判节：隐形设计的伦理）。
- 启动研究的书外可重复性待核（p.233），原文没点名研究者（批判节：心理学证据）。
- 线人例是作者假设的演示，没有游戏内的效果数据。

**各分支的已知缺口**

- 分支 1：何时不该推动未说明；效果强度原文没给。
- 分支 2：游戏内启动效果能持续多久，只有转述实验里的「几分钟」；元素数量和强度没有。
- 分支 3：原文只说玩家倾向于模仿；示范失败怎么办未说明；多人里怎么主动利用未涉及。
