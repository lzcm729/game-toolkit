# 平衡目标定位：公平方式与目标技能段

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> A game is FAIR when no player has an advantage at the start of play. … We can create asymmetric games that are deliberately unfair. This approach loses any sense of competitive legitimacy, but it unlocks unique experiences that can’t be had in a fair game.
>
> 译：开局时没有哪个玩家占优，游戏就是公平的。……我们也可以做刻意不公平的非对称游戏。这样做会失去一切竞技上的正当性，却能打开公平游戏给不了的独特体验。
>
> — Tynan Sylvester, *Designing Games*, Ch6 Balance / Balancing for Fairness, p.156–157

> It’s nearly impossible to make a skill-driven game that’s balanced for players of all skill levels. A designer must target which skill level he wishes to balance for, and allow the other skill levels to have degenerate strategies.
>
> 译：要做一款对所有技能段都平衡的技能型游戏，几乎不可能。设计者必须选定要为哪个技能段平衡，并允许其他技能段存在退化策略。
>
> — Tynan Sylvester, *Designing Games*, Ch6 Balance / Who to Balance For, p.163

> The answer depends on how much the game is about skill-driven challenge, and how much it is about other kinds of experience like art and story.
>
> 译：答案取决于这款游戏有多少是关于技能驱动的挑战，又有多少是关于美术、故事这类别的体验。
>
> — Tynan Sylvester, *Designing Games*, Ch6 Balance / Whether to Balance, p.165

## I — 方法骨架 (Interpretation)

这张卡处理平衡工作开始前的两个上游决定，定错了，后面每个平衡决定都会偏。

一是公平方式。作者的公平（fair）只看开局：开局时没人占优即公平，不是胜率相等。追求公平是为了让输赢有正当性。对称（symmetric，各方起点和规则完全相同）自动公平；非对称要靠仔细平衡才公平；还可以刻意不公平，用竞技正当性换历史探索、笑料这类体验。

二是目标技能段。不同水平的玩家能用的策略不同，同时为多个技能段平衡，要考虑的策略成倍增加，几乎做不到（p.164）。所以选一个段平衡，允许其他段有退化策略（某个决策里显然最好的策略）。选哪段，看游戏的意义多大程度来自技能挑战。

两个分支彼此独立，多在立项或定模式时各做一次。分支 2 的结论决定 `sylvester-degenerate-strategy-hunt.md` 找到的退化策略修不修，也决定 `sylvester-balance-change-review.md` 分支 4 要不要砍到底。

## A1 — 书中案例 (Past Application)

- **分支 1｜对称与非对称（转述，p.156–157）**：冰球双方起点和规则相同，自动公平；格斗游戏选不同角色、象棋白方先走、StarCraft 三个种族，都是非对称。很多时候对称做不到：象棋总得有人先走，Risk 的世界地图起始领土必然不同，二战游戏总得有人当轴心国。**刻意不公平（转述，p.157）**：历史战棋的玩家想知道德军能否从突出部战役的劣势中翻盘、日军能否守住硫磺岛，历史战役本就不公平，场景只能不公平；Cosmic Encounter 给每人古怪且不公平的能力，设计者说 Fair isn’t funny，所以没有竞技锦标赛，但极其好笑。
- **分支 2｜StarCraft II 优先顶端（转述，p.164）**：平衡团队公开说必须取舍时倾向最高水平玩家，保证专家层平衡，其余段能顾多少顾多少；作者认为这对一个供职业选手长期钻研的游戏是对的。**BioShock 的 Big Daddy（转述，p.164）**：本该是艰难的高潮战，却能用贴满感应雷的爆炸桶一击秒杀，或引进陷阱堆；这没关系，游戏不到 10 小时，很少有人摸到，摸到了游戏的意义也在叙事和角色扮演。Morrowind 的智力药水同理，玩家试一次就回去体验故事。原书未说明这些取舍的实际后果。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 立项或开新模式（排位、聚会、合作）时，要定这个模式追求什么样的公平。
2. 非对称游戏（不同阵营、角色、先后手）里，有人问要不要改成对称、非对称要平衡到什么程度。
3. 测出一个退化打法，团队争论要不要修；单人剧情游戏要不要组高手测试。
4. 平衡讨论里新手和高手的抱怨互相矛盾，没人写过目标技能段。

**语言信号**

- 要不要做对称 ／ 非对称要平衡到什么程度 ／ 聚会模式要公平吗 ／ 平衡给高手还是新手 ／ 这个退化打法要不要修 ／ 单机剧情游戏需要平衡吗 ／ 值不值得做高端平衡
- symmetric vs asymmetric ／ fairness ／ competitive legitimacy ／ balance for pros or casuals ／ target skill level ／ is high-level balance worth it

**与相邻卡的区分（初稿）**

- 找出某个技能段的退化策略、按段列表 → `sylvester-degenerate-strategy-hunt.md`（它的分支 2 是这里分支 2 的输入）
- 已定目标，具体怎么改一个工具 → `sylvester-balance-change-review.md`
- 多人对局里高手虐新手、新手拖累队友 → `sylvester-skill-gap-interdependence.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 要不要做对称；非对称该平衡还是可以不公平；某个模式的公平诉求 | 分支 1 |
| 平衡给哪个水平的玩家；退化打法修不修；值不值得投入高技能平衡 | 分支 2 |

### 分支 1：公平方案三选一：对称、平衡的非对称、刻意不公平

- **输入**：各方的起始处境和规则；这款游戏或这个模式要给玩家什么体验（竞技胜负、探索历史、笑料……）。体验说不清先问，不替设计者猜。
- **步骤**：
  1. 判断是否对称：各方起始处境和规则是否完全相同（p.156）。完成标准：标「对称 / 非对称」。
  2. 对称则公平自动成立，不必为公平做平衡（p.156），本分支结束。
  3. 非对称时看非对称是不是内在的（约定，由 p.157 三例推出）。原书说做成对称看似是达到平衡的简便办法，但非对称常常是游戏内在的，举了三例：象棋总得有人先走，Risk 的起始领土必然不同，二战游戏总得有人当轴心国，对称常常不是选项（p.157）；「不内在的可以考虑改成对称」是写卡时加的，由设计者判断。完成标准：标「内在 / 可改」。
  4. 在平衡的非对称和刻意不公平之间选：体验依赖竞技正当性（赢要能说明自己更强）的选前者（p.156）；以探索历史、制造笑料和离奇故事为目的的可以选后者，代价是失去竞技正当性（p.157）。完成标准：选定一项并写出依据的体验。
  5. 写下方案和理由；选平衡的非对称，就要列入仔细平衡的工作（p.157）。
- **判停 / 转向**：平衡到「够公平」的程度原文没有标准，那属于具体平衡和测试，转 `sylvester-degenerate-strategy-hunt.md`、`sylvester-balance-change-review.md`。同一款游戏既要竞技又要笑料，原文只有两端的例子，由设计者定。
- **输出**（约定）：公平方案说明，列为「对称与否 / 非对称是否内在 / 选定方案 / 是否放弃竞技正当性 / 理由」。

### 分支 2：目标技能段与高技能平衡投入决策

- **输入**：游戏的意义主要来自哪里（技能挑战，或美术、叙事、社交等）；已知或预期的退化策略及其技能段；测试资源。意义来源说不清先问。
- **步骤**：
  1. 承认几乎不可能对所有技能段都平衡，必须选一个目标段，允许其他段有退化策略（p.163–164）。
  2. 判断游戏的意义多大程度来自技能挑战，多大程度来自其他体验（p.165）。完成标准：归入「技能型、追求无尽深度」「不靠激烈技能竞争」或「两者并重」。
  3. 技能型：高技能平衡不可谈判，要穷尽式平衡测试与分析，否决平衡不了的虚构点子，接受低段失衡；作者举 StarCraft II、Counter-Strike、Street Fighter II（p.165）。
  4. 不靠激烈技能竞争：平衡到中低段，退化策略只要不完全明显即可；叙事或社交强的机制即使造成退化策略也可以保留；发售后被人发现也无妨（p.165）。
  5. 写下测试投入和有意接受的失衡：高段要有人研究数周到数月，发售后可能补丁多年；低段不需要长期研究和专门玩家；其他段能顺手补的就补（p.164–165）。完成标准：投入和接受的失衡各成一条清单。
- **判停 / 转向**：两者并重的游戏，原文只说取决于比重，没有细则；列出作者给的两端成本与收益，由设计者定。
- **输出**（约定）：目标技能段决定，列为「意义来源 / 归类 / 目标段 / 测试投入 / 接受的失衡 / 理由」。

## B — 边界 (Boundary)

**不要用这张卡**

- 要判断已有方案「够不够公平」、某个改动对不对 → `sylvester-balance-change-review.md`。
- 分支 2 只适用于技能驱动成分明显的游戏：作者的前提是技能型游戏（p.163），几乎没有技能挑战的游戏谈不上目标技能段。

**作者警告的失败模式**

- 想对所有技能段同时平衡，最后哪段都没平衡好。预警：讨论里同时引用新手和职业选手互相矛盾的抱怨；没写过目标段（p.163–164）。
- 叙事或社交驱动的游戏花大量资源追高技能平衡，挤占世界和故事（p.165）。预警：单人叙事游戏组专职高手测试；为一个少有人发现的退化打法推迟内容。

**作者盲点与时代局限**

- 公平只按「开局无人占优」定义，不涉及匹配、结算或对局中途的追赶机制。
- 团队规模默认中大型（编者评注，非原书）；成本按发售后打补丁的模式描述；例子写于 2012–2013。
- 单人游戏的退化策略修不修，第 16 章另有政治上能否接受的考量（p.368），本卡不覆盖。

**各分支的已知缺口**

- 分支 1：「够公平」没有判定标准；混合诉求（既要竞技又要笑料）原文没讲怎么处理。
- 分支 2：技能与叙事并重的混合型没有判据。
