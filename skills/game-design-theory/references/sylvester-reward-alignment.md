# 奖励对齐：该不该奖励这个行为

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> Extrinsic rewards can displace and even destroy the intrinsic fulfillment of play.
>
> 译：外在奖励会挤掉、甚至毁掉游玩本身带来的内在满足。
>
> — Tynan Sylvester, *Designing Games*, Ch8 Motivation and Fulfillment / Extrinsic and Intrinsic Motivation, p.212

> The principle of reward alignment basically says that you should only reward things that the player already wants to do.
>
> 译：奖励对齐的原则，说白了就是只奖励玩家本来就想做的事。
>
> — Tynan Sylvester, *Designing Games*, Ch8 Motivation and Fulfillment / Rewards Alignment, p.214

> And if we can’t detect it, we can’t reward it. … The goal of rewards design is to construct a system that can detect and appropriately reward everything the player already wants to do.
>
> 译：检测不到，就奖励不了。……奖励设计的目标，是造出一套能检测到、并恰当奖励玩家本来就想做的一切的系统。
>
> — Tynan Sylvester, *Designing Games*, Ch8 Motivation and Fulfillment / Rewards Alignment, p.215

## I — 方法骨架 (Interpretation)

这张卡回答「这个行为该不该奖励、怎么奖励才不伤玩法」。外在奖励指与活动本身分开的奖励（打兽人掉金币），内在奖励指活动本身带来的满足。作者认为两者不会简单相加：外在奖励会挤掉内在动机，活动越有趣、越偏探索和创造，挤得越厉害。解法是奖励对齐（rewards alignment）：奖励鼓励的活动与玩家没有奖励时本来会做的活动越重合，对核心体验的破坏越小。能不能对齐，取决于游戏能否检测到玩家达成了他想做的事。

三个分支：分支 1 在准备加奖励时按活动性质排风险；分支 2 是核心决策，按能否检测把玩家本来想做的事分成奖励、不奖励、介于之间；分支 3 接「介于之间」，做定制评分，评分管不到的目标做专门模式。常规顺序 1→2→3。

作者观点（参考单元）：「想要」与「喜欢」可以分离，玩家停不下来不说明他享受（p.205）。玩家悔恨（player's remorse）出现在玩家花时间玩了一个只给动机、不给满足的游戏之后（p.216）。作者描述了一条光谱：近端是对齐良好的奖励配有意义的核心，就是好设计；中段是强迫与满足交替，常由直接的工艺失误造成，奖励对齐得更好核心就更突出；远端是每个设计决定都围着动机最大化的强迫机器（p.217）。作者没给定位标准，对远端也不给处置答案（p.218）。「又爱又悔」的反馈按中段处理，交给分支 2。

## A1 — 书中案例 (Past Application)

- **分支 1｜Deci 的付费实验（转述，p.213）**：两组都做有趣的任务，第二天一组有报酬，第三天撤掉报酬；被付过钱的一组失去兴趣，从没拿过钱的一组照常投入。同类研究：有奖励时孩子画得更无趣，被付钱解过棋题的人空闲时解得更少。**钢琴课（作者亲历，p.213）**：照规定练了五年，16 岁老师不再来，他反而练得多得多，开始自由探索、作曲、即兴。
- **分支 2｜赛车与 SimCity（例题，p.214–215）**：赛车本来就是为了快，计时容易精确检测，也没什么别的动机会被计时毁掉，所以奖励圈速是对齐的；SimCity 里把城市建得像家乡、合作游戏里交到新朋友、Dwarf Fortress 里发明独特的水陷阱，游戏都检测不到，只能不设奖励系统。原书未说明结果。
- **分支 3｜Skate 3（转述，p.215–216）**：计分记录每次转体、翻板、滑杆、起跳和每毫秒滞空、每厘米滑行，按连招长度乘倍数，奖励的动作几乎就是玩家本来想做的；作者评价它玩起来是享受。反事实：若只奖励穿过漂浮圆环，玩家会无视其他系统。计分检测不到的竞速、把滑手摔得多惨、打磨一套连招，另做成竞速、复刻连招、Hall of Meat 等模式；模式的效果原书未说明。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 准备给某个玩法加成就、积分、任务或每日奖励。
2. 加了奖励后玩家只做拿奖所需的最少动作，探索、创造类玩法没人碰了。
3. 沙盒、创造、社交为核心的游戏，被要求「加点目标感」。
4. 评分或评级系统和玩家想玩的方式打架。
5. 玩家评价「核心很好玩但刷得想吐」「停不下来又后悔」。

**语言信号**

- 要不要加成就／积分 ／ 这个奖励会不会让玩法变味 ／ 玩家为了奖励去刷 ／ 沙盒要不要加任务 ／ 评分怎么设计 ／ 玩完觉得浪费时间
- should we reward this ／ achievements ／ extrinsic vs intrinsic ／ rewards alignment ／ overjustification ／ grind ／ player's remorse

**与相邻卡的区分（初稿）**

- 奖励何时给、玩家在哪个节点流失 → `sylvester-reward-schedule-diagnosis.md`
- 多人里玩家刷个人数据不推团队目标、捣乱 → `sylvester-divergent-goals-griefing.md`
- 给开发团队发奖金、做绩效激励（第 15 章，同一组词的另一种用法）→ 不是这张卡

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 打算给某个活动加奖励，想知道风险 | 分支 1 → 分支 2 |
| 该奖励什么、不该奖励什么；现有奖励把玩家引到别处 | 分支 2 |
| 玩家又爱又悔；刷子段拖累好核心 | 分支 2：把刷子段背后的奖励逐项过对齐（作者把这类交替归为工艺失误，p.217） |
| 有评分或评级系统，想让它奖励的就是玩家想做的 | 分支 3（先过分支 2） |
| 担心整个游戏做成强迫机器、想要伦理判定 | 没有分支：作者不给定位标准和伦理答案（p.218），见 I 段作者观点 |

### 分支 1：外在奖励替代风险排序（u08-06）

- **输入**：要挂奖励的活动；活动性质（重复枯燥 / 有趣 / 探索或创造）；拟加的奖励。性质说不清先问设计意图或试玩观察；活动有多有趣由设计者判断。
- **步骤**：
  1. 判断奖励是外在还是内在：与活动分开的是外在，与活动不可分的是内在（p.212）。完成标准：标明外在；内在奖励不进本分支。
  2. 按活动性质给序数风险（p.213–214）：枯燥任务没有内在动机可挤，外在奖励效果好（付钱挖坑）< 有趣的任务会被挤掉 < 越有趣挤得越多 < 探索、创造类最严重：人们不再玩乐式地探索，改做拿奖所需的最少动作，对以自由或创造为基础的游戏是致命的。完成标准：每项活动有一个序数位置和理由；不估「挤掉多少」。
  3. 有趣及以上的，不要随手撒奖励指望白捡动机（p.214），转分支 2。完成标准：每项写明去向。
- **判停 / 转向**：原文只有序数，没有程度量表或「损害多大不可接受」的阈值，由设计者判断。同一活动对不同玩家有趣程度不同时，原书未说明怎么处理。
- **输出**（约定）：表，列为「活动 / 拟加奖励 / 活动性质 / 序数风险 / 理由」。

### 分支 2：奖励对齐决策（u08-07）

- **输入**：玩家没有奖励也会自发去做的事的清单。原文没给调查方法；缺了先问它来自设计意图还是试玩观察，不替玩家编。
- **步骤**：
  1. 列出玩家本来想做的事；现有奖励也列出它实际鼓励的活动。对齐就是两者的重合程度（p.214）。完成标准：两列都填完。
  2. 逐项判断游戏能否检测到它已达成（p.215）。完成标准：每项标「能精确检测 / 检测不到 / 介于之间」；「介于之间」怎么划由设计者判断，作者把界线交给手艺。
  3. 按三档决定（p.214–215）：
     - 能精确检测，且没有别的动机会被奖励毁掉（赛车计时）→ 奖励
     - 检测不到（建得像家乡、交新朋友、发明水陷阱）→ 不设奖励。注意：作者说「不用奖励系统」，指的是核心动机都检测不到的创造、探索、社交类游戏，理由是奖励毁掉的动机可能比它制造的多；本卡按活动逐项套用，是推出的用法
     - 介于之间：有奖励的位置，但难做出完全对应内在欲望的系统 → 分支 3。作者说大多数游戏落在这里（p.215）

     完成标准：每项有去向。
  4. 现有奖励鼓励的活动不在玩家想做的清单里 → 标为未对齐。对齐越好对核心体验破坏越小，最好时两种动机才真正相加（p.214）。完成标准：未对齐清单。
- **输出**（约定）：对齐表，列为「玩家本来想做的事 / 能否检测 / 去向 / 依据页码」，另附未对齐的现有奖励。

### 分支 3：定制评分系统与专门模式（u08-08）

- **输入**：分支 2 标「介于之间」的活动；人判断这个活动做得「厉害」时看什么。
- **步骤**：
  1. 拆出人判断「厉害」时看的维度，做成细粒度的评分。Skate 3 记录每次转体、翻板、滑杆、起跳，每毫秒滞空、每厘米滑行，再按连招长度乘倍数（p.215）。完成标准：维度清单；权重和倍数留给设计者靠试玩校准。
  2. 对齐核对：评分奖励的动作，是否几乎就是没有奖励时玩家想做的动作（p.215）。失败信号是玩家只用能帮他拿分的系统、无视其余，反例是只奖励穿过漂浮圆环（p.216）。原书没有把它写成检验步骤：对齐的定义在 p.214，这一步由作者对 Skate 3 的评价和只奖励穿圈的反事实推出（约定）。完成标准：列出每个冲突。
  3. 列出评分检测不到、玩家却可能自发想做的非标准目标，为它们做带特殊胜利条件的专门模式（竞速、复刻别人连招、Hall of Meat，p.216）。完成标准：每个非标准目标对应一个模式，或写明不做。
- **判停 / 转向**：目标是检测并恰当奖励玩家想做的一切，每个游戏都要定制（p.215）。原书只有 Skate 3 一个案例，没给权重和倍数的调法。
- **输出**（约定）：评分维度表、冲突清单、专门模式清单。

## B — 边界 (Boundary)

**不要用这张卡**

- 奖励已经定了要给，只是排给奖时间、找流失节点 → `sylvester-reward-schedule-diagnosis.md`。
- 把作者对 Skinner 箱的立场当成伦理判定规则：作者声明本书讲工艺不讲伦理，只给一位设计师的看法（p.218）。
- 评分是为了让不同水平的玩家都有可达目标（弹性挑战，p.72–73）→ `sylvester-skill-range.md`，不是对齐问题。

**作者警告的失败模式**

- 往有趣、探索、创造类活动上随手挂积分、成就、奖品，玩家只做拿奖的最少动作，核心体验被掏空（p.213–214）。
- 给检测不到的目标设奖励，奖励只能落在可测的替代指标上，把玩家引离真正想做的事（p.215）。
- 奖励条件比玩家兴趣窄（只奖励穿圈），其余系统被闲置（p.216）。
- 强迫机器：玩家玩了、付了钱，最后只剩对浪费时间和金钱的悔恨（p.217）。远端只有 Cow Clicker 这个戏仿作范例：奶牛每六小时才能点一次，作者 Bogost 让奶牛消失后玩家还在点空地（p.217）。

**作者盲点与时代局限**

- 替代效应的证据是 Deci 等研究的转述，书外可重复性待核；成因作者只列了几种假说（p.214）。钢琴经历是作者个人案例。
- 反面典型停在 Facebook 社交游戏，抽卡、开箱、通行证、服务型运营没讨论（批判节）。
- 作者自称全书是模型和假设（p.375）；风险只有序数，光谱位置只有定性描述。

**各分支的已知缺口**

- 分支 1：只有序数，没有程度和阈值；同一活动因人而异时原书未说明。
- 分支 2：玩家内在欲望清单怎么调查，原文未给；三档的界线靠设计者判断；逐项套用是推出的用法，原文按游戏类型说。
- 分支 3：只有一个案例；权重调法原文没有；对齐核对是定性的。
