# 策略交互与均衡检查：对抗里有没有固定最优解

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> It only works when applied at the level of interactions between strategies, not entire designs.
>
> 译：博弈论只有用在策略与策略交锋的这一层才管用，套在整套设计上不行。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Games and Strategy Interactions, p.179

> A strategy interaction with one pure Nash equilibrium is a broken game design because it will always settle into that same equilibrium. Each player has only one viable option, so the strategic decision vanishes.
>
> 译：只有一个纯纳什均衡的策略交互是坏掉的设计，因为它总会落回同一个均衡。每个玩家都只剩一个可行选项，策略决策也就没了。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Nash Equilibria, p.180

> Rock-paper-scissors and matching pennies are the only elegant design patterns for strategy interactions—rock-paper-scissors for symmetrical games, and matching pennies for asymmetrical games.
>
> 译：石头剪刀布和 matching pennies 是策略交互仅有的两种优雅模式：对称的游戏用石头剪刀布，非对称的用 matching pennies。
>
> — Tynan Sylvester, *Designing Games*, Ch7 Multiplayer / Rock-Paper-Scissors and Matching Pennies, p.183

## I — 方法骨架 (Interpretation)

这张卡回答「多人对抗里某个交锋有没有固定最优解、克制关系怎么搭」。博弈论的分析单位是策略交互（strategy interaction）：各方的结果取决于对方的选择，而选的时候不知道对方选了什么；它分析一次交锋，不分析整局。纳什均衡（Nash equilibrium）是这样一种策略组合：对方不变时，谁单独换策略都得不到更好的结果。对局会被均衡吸过去，所以均衡的个数决定玩家还要不要揣摩对手。没有纯均衡的交互仍有混合均衡（mixed equilibrium）：各方按一定比例随机出招，均衡时每个选项的平均收益相等。matching pennies 是一种猜硬币游戏：一方想和对方对上，另一方想错开。

四个分支有先后：分支 1 拆出交互 → 分支 2 数纯均衡 → 要去掉均衡时分支 3 选骨架 → 收益不等时分支 4 估各选项会被用多频繁。这些都只是骨架，对抗的情感价值长在骨架外的读心博弈（yomi），那是 `sylvester-yomi-depth.md` 的事。

## A1 — 书中案例 (Past Application)

- **分支 1｜空城与守城（例题，p.176–179）**：拆空城堡是物理谜题，像单人游戏；攻有人守的城堡，对面的将领会预判你、回应你。设想攻守双方夜里各自备战：攻方在撞门和派工兵炸墙之间选，守方在城门备沥青和备弓手射工兵之间选，开战前互不知情。作者说胜负靠预判和欺骗，不靠更大的撞锤。博弈论解不了一整局 Mortal Kombat，却最适合分析零点几秒的拳、挡、投，或一次点球的射向与扑向。原书收益矩阵图缺失，只有文字。
- **分支 2｜猎鹿（例题，p.177–180）**：两个无法沟通的猎人各选猎鹿或猎兔；都猎鹿才吃得饱，猎兔稳得一小份，一人猎鹿一人猎兔则猎鹿者挨饿。有两个纯均衡：都猎鹿、都猎兔；后者对谁都不是最好，却稳定。攻城战没有纯均衡，每格总有一方想换。
- **分支 3｜克制环（转述 + 例题，p.181–184）**：格斗里挡克拳、投克挡、拳克投，策略游戏里枪兵、弓兵、骑兵互克，是对称的三角。非对称的有攻城、守两扇门的房间、布雷对扫雷，以及星际 2 人族对虫族的四单位（飞龙克坦克、机枪兵克飞龙、爆虫克扎堆的机枪兵、坦克远程炸爆虫）；作者称这组交互玩一百小时也不腻，因为没有均衡。石头剪刀布蜥蜴史波克每个符号克两个，作者判它在决策趣味上毫无增益。
- **分支 4｜点球（转述，p.186–187）**：作者引一项研究，用欧洲联赛数百次点球算出射手应 59.7% 踢强侧、40.3% 踢弱侧，总进球率 74.0%；改成 65% 踢强侧，遇到总扑强侧的门将只剩 72.6%。实测射手群体踢强侧的频率几乎正好是这个值。另有「赢石头得 5 美元」的变体（p.185），矩阵图缺失，原书没给答案。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 设计 PvP 的兵种、技能、招式之间的克制关系。
2. 测试里某个交锋总以同一种组合收场，玩家不看对手也知道怎么出。
3. 有人提议「多加几个兵种或姿态，博弈更丰富」。
4. 想知道改了某个选项的收益后，玩家的使用比例会往哪移。
5. 非对称对抗（攻守、躲与找）里想让双方都得猜。

**语言信号**

- 有没有最优解 ／ 克制关系怎么设计 ／ 石头剪刀布够不够 ／ 总是同一个打法 ／ 加兵种能不能加深度 ／ 这招会被用多少
- Nash equilibrium ／ payoff matrix ／ rock-paper-scissors ／ counter triangle ／ matching pennies ／ mixed strategy ／ PvP counters

**与相邻卡的区分（初稿）**

- 有没有心理博弈、虚张声势、信息战 → `sylvester-yomi-depth.md`
- 一招鲜对付的是关卡、内容或系统，不取决于预判对手 → `sylvester-degenerate-strategy-hunt.md`
- 一个太强的单位怎么改、单人决策里加选项能否加深度 → `sylvester-balance-change-review.md`
- 对手是 AI，或结果太随机 → `sylvester-decision-quality-audit.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 不知道从哪下手分析一个多人模式 | 分支 1 → 分支 2 |
| 某个交锋是不是总落到同一个组合 | 分支 2 |
| 要设计克制关系；有人提议加选项 | 分支 3（先过分支 2） |
| 收益不等，想估各选项会被用多频繁 | 分支 4 |

### 分支 1：找出策略交互

- **输入**：玩法或模式描述，至少说得清某一刻各方能做什么、彼此看得见什么。缺了先问。
- **步骤**：
  1. 逐个情境判断：是一个人面对机械系统（拆空城、算物理），还是对面有人在想你、会预判和回应你（p.176）。完成标准：每个情境标「机械挑战 / 策略交互」。
  2. 策略交互要满足：各方结果取决于对方的选择，选的时候不知道对方选了什么（攻守双方夜里各自备战，p.176–177）。零和、合作、目标部分一致的都算（猎鹿，p.177）。完成标准：每条交互标类型。
  3. 粒度取到一次交锋：一次拳、挡、投的对拼，一次点球的射向与扑向；不把整局当一个博弈（p.178–179）。完成标准：每条记下参与方、各方选项、选时看不到什么。
- **判停 / 转向**：对手是 AI 时原文没讲。三方以上的交锋怎么拆，原文没说，照实标出。
- **输出**（约定）：交互清单，列为「情境 / 参与方 / 各方选项 / 隐藏了什么 / 类型」，交分支 2。

### 分支 2：纳什均衡检查

- **输入**：一条两方、离散选项的交互；每格各方结果的相对好坏，由设计者估计。原文没给收益的估法，设计者说不出相对高低就先问，不替他填。
- **步骤**：
  1. 画收益矩阵：每格是一种策略组合，填各方结果（p.176、p.179）。完成标准：所有组合都有格。
  2. 逐格问：对方不变时，有没有哪一方单独换策略能更好（p.179）。完成标准：每格标「谁想换 / 没人想换」。
  3. 没人想换的格是纯纳什均衡，数个数；均衡不一定对谁都最好（都猎兔，p.179）。完成标准：均衡格与个数。
  4. 判定（p.180）：玩法会向均衡收敛，非均衡的格基本不会出现。一个纯均衡判坏设计，人人只剩一个可行选项，不必揣摩对手，作者说这就是单调；多个较好；没有最好。完成标准：三选一的结论。
  5. 有纯均衡就重设计或重平衡去掉它（p.180）；换结构转分支 3。
- **判停 / 转向**：具体怎么调数值不在本分支。
- **输出**（约定）：矩阵、均衡标注、个数、结论。

### 分支 3：无均衡模式选型

- **输入**：一条要做成无纯均衡的两方交互；双方招式是否相同；若有加选项的提议，一并给出。
- **步骤**：
  1. 双方招式相同为对称（p.181）。
  2. 对称用石头剪刀布三角：每招克一招、被一招克，是对称交互里最简单的无均衡结构（p.181）。非对称用 matching pennies：一方想对上，另一方想错开（攻城、两门房间、布雷与扫雷、星际四单位，p.182–183）。完成标准：写出完整的克制关系。
  3. 对「往克制环里多加符号」的提议（石头剪刀布蜥蜴史波克）：没有均衡加了还是没有均衡，预判与欺骗的心理博弈不会更丰富；可能多些虚构趣味，但多半不值多出来的学习负担（p.183–184）。完成标准：默认否决并写理由，虚构趣味与学习负担由设计者权衡。
  4. 注明这只是骨架，情感价值在骨架外的 yomi（p.187），转 `sylvester-yomi-depth.md`。
- **判停 / 转向**：三方以上的交互不在本分支。收益不等时仍无纯均衡，要估各招的使用比例时转分支 4。
- **输出**（约定）：选型说明：模式、克制关系、对加选项提议的结论。

### 分支 4：混合均衡的等收益估算

- **输入**：一条已无纯均衡、收益不等的 2×2 交互，四格收益由设计者给出。原书示例里一方之得即另一方之失（进球率）；收益不对立的情形原文没示范。
- **步骤**：
  1. 写出四格。点球例：强侧对扑强侧 63.6%、强侧对扑弱侧 94.4%、弱侧对扑强侧 89.3%、弱侧对扑弱侧 43.7%（p.186）。
  2. 找比例：一方的混合比例要让对方每个选项的平均收益相等（p.187）。设本方选第一项的概率为 p，a、c 是对方选 X 时本方两项的收益，b、d 是对方选 Y 时的，解 p·a+(1−p)·c = p·b+(1−p)·d。求解式按正文重建，原书只给结果。完成标准：p 与均衡期望值。
  3. 核对：点球应得强侧 59.7%、弱侧 40.3%、进球率 74.0%（p.186）。完成标准：复现这组数。
  4. 推演偏离：一方偏离比例，对手就改用纯策略剥削；射手强侧踢到 65%，门将总扑强侧，进球率降到 72.6%（p.186–187）。完成标准：写出偏离方向、对手的纯策略、损失。
  5. 读设计含义：改收益就改比例（p.189）；玩家不会算，但群体凭直觉能找到接近均衡的比例（p.187）。
- **判停 / 转向**：作者说设计师不必算数，等收益是直觉工具（p.185、p.187）；收益给不出数时只用直觉版，找让每个选项平均收益相同的比例。3×3 以上（赢石头得 5 美元）原文没给答案，不在本分支。
- **输出**（约定）：比例、期望值、偏离推演、一句设计含义。

## B — 边界 (Boundary)

**不要用这张卡**

- 判断有没有心理博弈、读心空间 → `sylvester-yomi-depth.md`。本卡只看骨架。
- 对手是 AI；三方以上的交互；3×3 以上的混合均衡：原文都没示范。
- 想要收益的具体数值：原文没说怎么估，真实游戏的收益本来就模糊难量化（p.188–189）。

**作者警告的失败模式**

- 单一纯均衡：交锋总收敛到同一组合，玩家不必想对手，单调（p.180）。
- 因为博弈论解不了整局，就整个弃用（p.179）。
- 往克制环里堆符号当加深度（p.183–184）。作者在第 6 章自承曾按「可行策略越多越平衡」写完一整章，被石头剪刀布蜥蜴史波克和扑克两个反例推翻（p.161–162）。

**作者盲点与时代局限**

- 「只有这两种是优雅模式」是作者的断言（p.183）。
- 均衡个数的优劣：作者先说多个或没有都行，后说最好全部去掉（p.180）；本卡按「没有最好、多个次之、唯一为坏」写。
- 攻城、猎鹿、石头剪刀布、matching pennies、星际四单位、赢石头得 5 美元的图在转换中丢失，案例只按正文文字重建。
- 点球数据来自作者转述、未点名的研究；那张表在转换中被误标成页边要点。
- 收益靠设计者估计；对局统计、遥测、自动模拟作者几乎没谈（编者评注，非原书）。作者自称全书是模型和假设（p.375）。
