# 技能深度的层次

> **怎么用这张卡**：它是方法和书中依据的来源之一，不是回答的模板。回答围绕用户的处境：先给你自己的专业判断和具体做法，书外的实操（算一个例子、查数据、估成本）照常给；再用这张卡补方法、校正判断。不要按卡的分段复述这本书；卡里没写的，不等于不能答。书名和页码只在用户要出处时给。

## R — 原文 (Reading)

> Games broaden their skill range by repeatedly REINVENTING themselves as the player’s skill increases.
>
> 译：游戏随玩家技能提高一次次重塑自己，以此拓宽技能区间。
>
> — Tynan Sylvester, *Designing Games*, Ch3 Skill / Reinvention, p.70

> Games tend to go through three characteristic reinventions along their skill range: the MANUAL, the SITUATIONAL, and the MENTAL.
>
> 译：游戏沿技能区间往往经历三次典型的重塑：操作层、局面层、心智层。
>
> — Tynan Sylvester, *Designing Games*, Ch3 Skill / Reinvention, p.71

> Given a toy, most people will almost immediately set themselves a goal within it. … If that newly invented game is trivially shallow, the design has failed.
>
> 译：给一个玩具，大多数人几乎立刻就会在里面给自己定个目标。……如果这个新发明的游戏浅得一眼看穿，设计就失败了。
>
> — Tynan Sylvester, *Designing Games*, Ch3 Skill / Skill Without Explicit Goals, p.68

## I — 方法骨架 (Interpretation)

这张卡回答「玩家学会以后为什么腻、深度断在哪」。作者的观点：一种简单技能撑不了多久，瞄准、走位、经济策略、地图门道都只能学那么久；深的游戏是一层套一层，玩家把一层练到不用想之后，下一层挑战露出来。没有下一层，玩家就碰到天花板、失去兴趣（p.69–70）。重塑（reinvention）就是这种换层。

三层：操作层（manual）是掌握界面，所有游戏都从这里开始；局面层（situational）是操作已近于下意识，挑战变成打谁、何时、派什么去哪，包括局势感知、读套路、懂反制，这一层很宽、内部还能再分；心智层（mental）是保持专注和状态、预测并操纵对手的心理（p.71）。

没有官方胜负的玩具型游戏也逃不开深度：玩家会自己定目标，变成他自创的技能游戏（p.68）。

两个分支互相独立：有胜负的技能游戏走分支 1；沙盒、玩具走分支 2。分支 2 判断深浅时可借 `sylvester-skill-range.md` 分支 2 的天花板估计。

## A1 — 书中案例 (Past Application)

- **分支 1｜Unreal Tournament（作者亲历，p.69–70）**：第一周作者在意的是酷角色和大爆炸；一周后虚构被剥掉，挑战是瞄准；瞄准变成肌肉记忆后，变成控图（抢好道具和狙击点）；控图不用想了，变成追踪对手（他掉血会去拿血，远距离交火会去拿狙）并设陷阱；最后变成扑克式的心理战：激怒对手、混用策略、读心。作者说自己从没掌握最后一层，因为它无限深；控图和追踪两层他都归为局面层（p.71）。
- **分支 1｜三层的一句话例（例题，p.71）**：操作层：射击游戏把准星稳在目标上，Tetris 让方块按想要的朝向落到想要的位置，象棋学每个子怎么走；局面层：操作已近下意识（格斗游戏随手打出多键连招），挑战变成打谁、何时打、派什么去哪；心智层：高水平时一次情绪波动或分神就输，有专门激怒、干扰对手的战术。
- **分支 2｜The Sims（转述，p.68）**：没有预设目标，但玩家会决定「尽量赚钱」，这时他玩的已是自创的「The Sims：尽量赚钱」，它若浅得一眼看穿，设计就失败了。孩子拿积木会想堆更高，拿球会想扔更远。原书未说明结果。

## A2 — 触发场景 (Future Trigger) ★

**情境**

1. 玩家通关或玩几十小时后说「没什么可学的了」。
2. 长线、竞技游戏要规划后期深度，或评估某层是否会被解开。
3. 单人游戏立了「能玩上百小时」的目标，要判断现实不现实。
4. 沙盒、模拟、创造类游戏没有胜负，团队以为不用管深度。

**语言信号**

- 学会就腻了 ／ 玩透了 ／ 后期没深度 ／ 高手玩法没有新东西 ／ 沙盒里玩家玩什么 ／ 玩家自己定的挑战太简单
- mastery ／ depth ／ reinvention ／ endgame ／ late-game depth ／ sandbox ／ toy ／ player-set goals

**与相邻卡的区分（初稿）**

- 天花板在哪、区间要不要宽 → `sylvester-skill-range.md`
- 多人对抗里的读心、虚张声势（心智层的具体做法）→ `sylvester-yomi-depth.md`
- 按决策规模看深度（第 5 章）→ `sylvester-decision-rhythm-mapping.md`
- 沙盒缺故事感 → `sylvester-emergent-story.md`

## E — 执行 (Execution)

### 先选分支

| 你的问题像…… | 走 |
|---|---|
| 有胜负的技能游戏，学会后腻、后期没东西 | 分支 1 |
| 没有官方胜负的沙盒、玩具 | 分支 2 |

### 分支 1：Reinvention 层次诊断（u03-06）

- **输入**：各阶段玩家在练什么、难在哪；单人还是多人；目标游玩时长。缺了先问。
- **步骤**：
  1. 把技能结构写成三层：操作层（掌握界面）、局面层（读局面、懂反制，可再分几个内部层）、心智层（保持专注与状态、预测和操纵对手心理）（p.71）。完成标准：每层写出本作的具体挑战，或写「无」。
  2. 逐层检查：这一层练到下意识之后，是否露出下一层（p.69–70）。
  3. 掌握后没有下一层的地方，标为深度断层：更浅的游戏在这里就没东西可练了（p.69）。完成标准：断层位置及理由。
  4. 心智层单独看：作者说只有专注投入的竞技高手才会到达；大多数无限深的游戏是多人游戏，因为人能学会几乎任何系统，却永远读不透另一个人（p.71）。单人游戏在这一层多半写「无」。
- **判停 / 转向**：怎样造出下一层，原书没给，本分支只做诊断。断层要不要补，看这款游戏的区间要不要宽 → `sylvester-skill-range.md` 分支 3；作者说不是每个游戏都要无限深，意义也来自美术、探索、叙事的游戏可以不追求多层深度（p.65，Assassin's Creed II 一例）。心智层的具体手段 → `sylvester-yomi-depth.md`。
- **输出**（约定）：层次表，列为「层 / 本作的挑战 / 掌握后是否露出下一层 / 断层说明」。

### 分支 2：无目标玩具的技能检查（u03-04）

- **输入**：玩具能做的交互；目标玩家。
- **步骤**：
  1. 查使用门槛：阅读、鼠标、界面、读懂事件意义的文化背景（p.68）。已用 `sylvester-skill-range.md` 分支 1 列过的直接沿用。
  2. 预测玩家会给自己定哪些目标（堆更高、扔更远、赚最多钱）（p.68）。完成标准：目标清单。
  3. 逐个检查自创目标是否浅得一眼看穿；浅即设计失败（p.68）。可借 `sylvester-skill-range.md` 分支 2 的天花板估计判断。完成标准：每个目标标「浅 / 有深度」及理由。
  4. 补救方向：让玩具表达有趣、不显然、可以学会的性质（p.68）。
- **判停 / 转向**：玩家实际会定什么目标，只能由设计者预测，原书没给收集方法，目标清单的完整性不作承诺。偏审美表达的目标（如把家布置得最漂亮）算不算技能游戏，原书未说明。
- **输出**（约定）：「自创目标 / 深浅 / 理由 / 补救方向」表。

## B — 边界 (Boundary)

**不要用这张卡**

- 只想知道天花板高低、区间宽窄 → `sylvester-skill-range.md`。

**作者警告的失败模式**

- 被解开的游戏：玩家拼命想解开它，真解开了就恨设计者，因为没东西可学、没有不确定性（p.64）。
- 玩具里玩家自创的游戏浅得一眼看穿（p.68）。

**跨章条件**

- 第 5 章：同一个决策会随玩家学习从不可能变成 profound、tactical、twitch，最后变成不是决策（p.142），是从决策规模看「层」的另一种写法，见 `sylvester-decision-rhythm-mapping.md`。
- 第 7 章：对局面和对手的评估挑战把天花板推得极高（p.191），见 `sylvester-yomi-depth.md`。

**作者盲点与时代局限**

- 主要案例是作者的 Unreal Tournament 亲历，其余是一句话例；三层是作者从射击、RTS 经验归纳的「典型」层次。
- 心智层只有少数竞技高手会到达（p.71）。
- reinvention 区间图原图缺失（转换时丢失），三层靠正文重建。

**各分支的已知缺口**

- 分支 1：怎样造出下一层原书未说明；「某层已掌握」没有判据。
- 分支 2：第 1 步与 `sylvester-skill-range.md` 分支 1 重复；自创目标靠预测；「太浅」没有阈值。
