# 建模—推演—验证—更新：数值问题的工作环

## 一句话

数值问题不靠「跑一批看看」回答。先把机制写成一个能算的模型，用已有数据校准；用它算出每一格的预期（带算式和预计波动）并**写下来**，再去跑；跑完先核执行与测量，再逐格判相容／方向对幅度失配／失配；失配先定位、修模型，再决定下一批。一轮回答一个问题，环转到问题答了、原问题变了或胃口用完为止。

**REQUIRED BACKGROUND：** game-dev-lessons 的「数值模拟与调参」（样本量、杠杆极值、快慢工具分歧、合并后重采基线）与「五格」（问题行、机制准入）。本 skill 不重复那些判据，只定工作环的形状。试验可以为问题行取证，但试验达标不构成机制准入：结果若导向新增机制或改规则，转五格与项目自己的拍板流程。

## 什么时候用

- 要跑模拟器、数值尺、批量自动化测试来回答平衡、强度、节奏、经济类问题
- 一个杠杆改了「没效果」，或两种策略的差距怎么调都出不来
- 刚拿到一批结果，要决定下一批跑什么
- 有人（包括你自己）说「先扫一遍参数再说」

不用于：机制取舍的讨论（即使带数字）；要不要加某机制的准入判断；一次性查某个值、确定性算术。

## 工作环

每一步留下的东西按 [references/loop-template.md](references/loop-template.md) 的**必填字段**填；只有标题、占位符或「稍后算」不算完成这一步。

| 步 | 做什么 | 留下什么 |
|---|---|---|
| 0 问题行 | 现象与出处；现行做到多少、已有机制是什么、不改的损失；本轮要回答的一个问题，证据用于哪个决定。判据写来源：沿用哪条已定目标、谁定的；没有既定目标时，自己提的阈值标「探索用临时判据」。样本量写依据：指标单位、足以改变决策的差值、已知噪声；噪声未知先估噪声再定确认批。胃口写成额度或逐轮决定点 | 问题行 ＋ 判据（来源、样本量依据、胃口） |
| 1 建模并校准 | 先核旧数据与当前代码、参数、代理、口径兼容；本轮要合并或换版本的，先完成再复刻基线，不兼容的数据不当校准锚。把机制写成能算的账，每个量写来源，校准项单独标。校准表写明锚点覆盖了本轮哪些策略、配置和决定结果的阶段，模型值对实测值、偏差、接受依据；未覆盖或未通过的单列，不用一个锚点代表整模型可用。没有可用旧数据：按明确假设建初始模型，先安排一个只为校准的最小批 | 模型文件 ＋ 校准表（覆盖范围、未通过项） |
| 2 推演 | 每格写预测的指标与单位、点预测与算式（或模型版本）；随机指标附本批样本量下预计的波动范围及依据，确定性指标附容差。分开写两种判据：目标达标判据、模型失配判据（偏到哪算模型错、会错在哪一项） | 「推演与预期」一节，开跑前写完并冻结 |
| 3 验证 | 开跑前核实际条件与预测记录一致（版本、参数、代理、工具）；条件变了就暂停这批、更新基线、回第 1 步，旧预测保留并标失效。最小批定方向，确认批用没用过的种子。记录本批用的工具、代理覆盖与结论用途（相对筛选还是最终签收） | 原始数据 ＋ 版本戳 ＋ 工具记录 |
| 4 对照 | 先核执行条件与测量有效性。再逐格写：冻结的预测、实测与样本数、差值、模型判断（相容／方向对幅度失配／失配／证据不足）、目标是否达标——两种判断分列。失配原因写「已定位／待定位」及证据，不把候选解释写成已知原因 | 对照表 |
| 5 更新模型 | 改了什么及证据，或为何不改；重跑校准表（用来改模型的数据，重跑只算校准回放）。剩余缺口写影响条件、指标、已知偏差与本批预测的具体处理；缺口足以改变格的选择或达标结论、又无法量化的，下一批先诊断它，不口头打折后继续确认。列出本次更新让哪些旧结论失效、降级或仍成立 | 新版模型 ＋ 缺口清单 ＋ 撤回清单 |
| 6 下一批 | 先判原问题及其依据是否仍成立：变了回第 0 步；没变按停止条件选继续、换方向或停。继续时由当前有效的模型选最能分辨候选解释的格，写明它区分什么不确定性；失配原因未定位前，不按失效的模型选调参格 | 下一批的「推演与预期」 |

## 停机与升层

- 判据过或明确不过、原问题被推翻、或胃口用完，就停；不因「再跑一批也许就行」续。
- 同一失败形态第二次出现，或连改三次结果不动：停在这一层，查改动真被执行到了没，再退一层查前提、结构或测量工具。
- 多次确认没见到足以改变决策的改善：按约定的停止条件收，报已测范围、最好实测结果及其不确定性。重复几次相近不证明上限；只有列明约束并推出界限时，才报「该约束下的模型上限」。
- 确认批开跑前固定预测；看过确认结果再改模型，这批就不能再当新版模型的独立确认，新版另开确认批。

## 常见错法

| 错法 | 为什么错 | 改成 |
|---|---|---|
| 把判据当预期（「成功率到目标阈值才算过」） | 判据不告诉你模型对不对；跑完只知过没过，不知道哪一项猜错 | 判据之外写模型算出的数字与预计波动 |
| 预期写成凭感觉的区间 | 对了不知为什么对，错了修不了模型 | 每个数带算式与来源；有依据的波动范围与点预测并列不算违规 |
| 实测一偏离点预测就改模型 | 随机结果不会恰好等于点预测；偏差也可能来自版本、代理、测量 | 先核执行与测量，再按跑前写的失配判据判 |
| 用合并各配置的分布当成与配置无关 | 节奏一变分布就变 | 校准用同配置的锚 |
| 几个固定种子跑出的「处处 100%」当定论 | 几个种子只是几个种子 | 确认批换没用过的种子、按样本量算区间 |
| 合并别人的改动后直接续跑 | 基线漂了，差异记到了你的杠杆头上 | 先复刻基线逐场比旧结果 |
| 全程平均掩盖阶段 | 关心的阶段只占全过程一部分，均值把它抹平 | 按阶段拆开量，报各阶段占比 |
| 结果不符就换一个参数再跑 | 模型错着，再跑多少都在错的地图上搜索 | 先定位、修模型、重跑校准表 |
| 直觉与模型相反时信直觉 | 直觉没有算式可查 | 两个都写下，让数据判，赢的留 |
| 重复几次结果相近就报「上限」 | 相近只说明这个配置稳定 | 报已测范围与最好结果；上限只在列明约束推出界限时报 |
| 把关键误差登记成「已知缺口」后继续打折确认 | 缺口会改变达标结论时，打折只是猜 | 下一批先诊断缺口 |

## 报告怎么写

每批一节：跑前冻结的预期 → 实测表 → 逐格对照（模型判断与达标判断分列，失配写已定位／待定位）→ 模型改了什么、哪些旧结论撤回 → 下一批或停。给决策者的收口只写：验过的猜想对错清单、能用的结论（带已测范围与不确定性）、剩下要拍的几个方向各一句后果。
