# 工作环的模板与一个精简例子

## 一、每批的记录（开跑前写完前三段，跑完补后三段）

```
### 第 N 批（场景名、时间）开跑前的推演与预期
问题行：这一批回答什么问题；判据与样本量（先写死，之后不改）
用的量：<量＝值（来源：代码常量／设计值／第 K 批实测，日期）> …
模型：<算式一行一条> → 逐格预期表
| 格 | 打法／策略 A | 策略 B | … | 关键差 |
|---|---|---|---|---|
| 配置 1 | 预期数字（算式要点） | … | | |
猜想错了会怎样：<什么结果说明错了；错会出在模型哪一项>

### 第 N 批结果与对照
| 格 | 实测 | 预期 | 判（全中／方向对幅度错／错） | 错在哪一项 |
模型改了什么：<改动与新校准值>；仍对不上的（已知缺口）：<条目、幅度、影响哪类预期>
下一批：<由更新后的模型选的格、理由>
```

写法要求：预期是数字，不是「会变好」；每个数能回溯到算式；「对的算对、错的算错」，对照表里不许事后把预期改宽。

## 二、模型文件的骨架

```
头部注释：每个量与来源（常量从哪个文件、设计值哪页、实测哪一批）；哪些是校准项（拟出来的，不是量出来的）
参数：机制旋钮（可被试验覆盖）＋ 校准项（用已有数据拟合）
核心循环：按机制的最小周期写账（每周期各方得失、触发条件、终局）
cell(配置, 策略) → 成功率、失败构成、用时、代价 的分布
校准表：已有的格 → 模型值对实测值（先跑这张表，复现不了先修模型）
预测表：待跑的格
因子表：以某配置为基准，每个因子单独动一步，看各策略的变化与差距变化（告诉你哪个旋钮碰的是哪一段）
```

校准的次序：先对最简单、变量最少的格（例如不读任何信号的策略），再对复杂的；拟合的系数标成校准项，不混进「量出来的」里。

## 三、精简例子（示意数字）

问题行：钓鱼搏斗里三种打法——一直收、盲放（鱼冲就放线）、看局面（读张力再决定）——玩家反馈「没有要权衡的选择」；目标是看局面要有优势；判据：困难鱼上看局面上岸 ≥26/30 且比盲放净多救 ≥6（跑前写死）。

建模：每个冲刺周期鱼掉的体力 ＝ 冲刺起手扣 ＋ 放线耗（系数×满力僵持耗×放线时长）＋ 顶着耗（没游成的米数×单价）；盲放的线预算决定它什么时候被迫顶住；鱼还强着时顶住有被拖下水的风险（按每个顶着的冲刺算，系数用已有 30 场拟合）；竿磨损按绷线时长与张力分段。

校准表（节选）：一直收三种鱼模型 70／54／37% 对实测 77／53／40%；盲放四个格 66／89／93／96% 对 63／87／97／100%。对不上的：看局面在 90 秒以上搏斗的断竿，模型偏乐观——记为已知缺口，凡拉长搏斗的杠杆给看局面的预期打折。

推演（节选）：加大鱼的体力池——冲刺扣是比例时，模型说无差距（两种打法掉的比例一样）；改成固定点数后，模型说差距随体力池涨但搏斗变长、磨损同涨。疲劳从满体力起线性衰减会抹平差距（盲放顶住时鱼已被压弱）；疲劳起点推后（前半场满力）保留差距。

验证与对照（节选）：体力池 ×2 实测盲放 5/5——模型「无差距」对；疲劳起点 0.4 四格盲放各下水 1 场——方向对；短线让盲放提前顶住——模型「不会下水」对，直觉「会下水」错，但模型漏算了磨损（线短让绷线时间大增，各断一场）→ 更新模型的磨损项。

停机：三次 30 场确认都落在净 +3～+4，模型说再大只能拉长搏斗而磨损先断看局面的竿——报「上限约 10 个百分点」，把判据怎么定交回决策者，不再找旋钮。
