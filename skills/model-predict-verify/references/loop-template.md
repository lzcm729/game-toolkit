# 工作环的模板与一个精简例子

## 一、每批的记录（开跑前写完前三段并冻结，跑完补后三段）

```
### 第 N 批（场景名、时间）开跑前的推演与预期
问题行：现象与出处；现行做到多少、已有机制、不改的损失；这一批回答什么问题；证据用于哪个决定
判据：目标达标判据（来源：沿用哪条已定目标、谁定的；或「探索用临时判据」）；样本量及依据（指标单位、足以改变决策的差值、已知噪声）；胃口（额度或下一次决定点）
条件：代码版本／参数／代理／工具；与校准数据是否兼容
用的量：<量＝值（来源：代码常量／设计值／第 K 批实测，日期）> …
模型：<算式一行一条；模型版本> → 逐格预期表
| 格 | 策略 A | 策略 B | … | 关键差 |
|---|---|---|---|---|
| 配置 1 | 点预测 ± 预计波动（算式要点） | … | | |
失配判据：<偏到哪算模型错；错会出在模型哪一项>

### 第 N 批结果与对照
执行与测量核对：<版本一致？代理按定义工作？测量口径没变？>
| 格 | 冻结的预测 | 实测（样本数） | 差值 | 模型判断（相容／方向对幅度失配／失配／证据不足） | 达标？ |
失配原因：<已定位（证据）／待定位（候选解释，各自预测什么）>
模型改了什么：<改动与证据，或为何不改；校准回放结果>；剩余缺口：<影响条件、指标、已知偏差、本批预测怎么处理的>
旧结论：<哪些失效、降级、仍成立>
下一批或停：<原问题是否仍成立；由更新后的模型选的格、它区分什么不确定性；或停止理由>
```

### 必填字段（缺一项就不算完成那一步）

| 必填项 | 完成所需内容 |
|---|---|
| 问题行与判据 | 现象与出处；现行做到多少；本批问题；判据来源与谁定的；样本量依据；胃口 |
| 校准 | 本轮适用锚点、模型值、实测值、偏差、覆盖范围（策略、配置、阶段）及未通过项 |
| 逐格预期 | 每格的配置与策略、预测指标及单位、点预测、预计波动或容差、算式或模型版本、失配判据 |
| 逐格对照 | 跑前冻结的预测、实测及样本数、差值、模型判断、目标是否达标，两种判断分列；失配写已定位／待定位 |
| 模型更新 | 改了什么及证据，或为何不改；校准回放结果；剩余缺口及处理；撤回的旧结论；下一批或停止的理由 |

写法要求：预期是数字，不是「会变好」；每个数能回溯到算式。本批开跑后不追改判据或预期；目标改变另起一轮，旧批保留原判据；扩样按跑前约定执行。「对的算对、错的算错」：对照表里不许事后把预期改宽。

## 二、模型文件的骨架

```
头部注释：每个量与来源（常量从哪个文件、设计值哪页、实测哪一批）；哪些是校准项（拟出来的，不是量出来的）
参数：机制旋钮（可被试验覆盖）＋ 校准项（用已有数据拟合）
核心循环：按机制的最小周期写账（每周期各方得失、触发条件、终局）
cell(配置, 策略) → 成功率、失败构成、用时、代价 的分布（给点预测与分位数，不只给均值）
校准表：已有的格 → 模型值对实测值、偏差；写明覆盖了哪些策略、配置、阶段，哪些没过（先跑这张表，复现不了先修模型）
预测表：待跑的格（冻结在开跑前；看过结果后改的模型，另开确认批）
因子表：以某配置为基准，每个因子单独取有机会产生可检出效果的幅度（按「数值模拟与调参」第 4 条先验杠杆、再收敛），写出各策略与差距的预测变化
```

校准的次序：先对最简单、变量最少的格（例如不读任何信号的策略），再对复杂的；拟合的系数标成校准项，不混进「量出来的」里。用来拟合的数据不再充当独立验证。

## 三、精简例子（示意数字，成套重造，不是任何项目的实测）

问题行：钓鱼搏斗里三种打法——一直收、盲放（鱼冲就放线）、看局面（读张力再决定）——玩家反馈「没有要权衡的选择」；现行：拖得动就一直收，否则切线，三种打法的成功率没差别；目标是看局面要有优势。判据（设计者定、跑前写死）：困难鱼上看局面的上岸率不低于可靠线 p₀，且比盲放配对净多救不少于 d₀ 场；样本量按能分出 d₀ 的二项噪声定；胃口：当天之内、最多三个确认批。

建模：每个冲刺周期鱼掉的体力 ＝ 冲刺起手扣 ＋ 放线耗（系数×满力僵持耗×放线时长）＋ 顶着耗（没游成的米数×单价）；盲放的线预算决定它什么时候被迫顶住；鱼还强着时顶住有被拖下水的风险（按每个顶着的冲刺算，系数用已有确认批拟合）；竿磨损按绷线时长与张力分段。

校准表（节选，示意）：一直收三种鱼 模型 72／55／38% 对实测 75／52／41%；盲放四个格 模型 65／88／94／97% 对实测 62／86／96／100%。覆盖：一直收与盲放在 60～75 秒搏斗里的上岸率；**未覆盖**：看局面在 90 秒以上搏斗的断竿——模型偏乐观，登记为缺口，凡拉长搏斗的杠杆，看局面的预期不可直接用，要先诊断。

推演（节选）：加大鱼的体力池——冲刺扣是比例时，模型说两种放线打法掉的比例一样、差距不变；改成固定点数后，模型说差距随体力池涨、搏斗同时变长、磨损同涨。疲劳从满体力起线性衰减会抹平差距（盲放顶住时鱼已被压弱）；疲劳起点推后（前半场满力）保留差距。每格写点预测与 5 场或 30 场下的预计波动。

验证与对照（节选）：体力池 ×2 的 5 场探索批，盲放与看局面都全上岸——只记为探索观测：5 场分不出差距，模型「无差距」既没被证实也没被推翻。疲劳起点推后的四格里盲放各出现一次下水——对照跑前写的「盲放下水率 10%～15%、看局面 0」属相容，样本小，方向待确认批。短线让盲放提前顶住——模型「不会下水」对，直觉「会下水」错；但两边各断一根竿，模型漏算了绷线时间大增带来的磨损 → 失配已定位，更新磨损项，重跑校准表。

停机：三个确认批的净增益都落在约定差值 d₀ 的一半左右，没有达到目标；当前模型认为沿「拉长搏斗」方向继续会先撞上磨损约束，于是停这一方向。报告写：已测范围、最好的实测差距及其区间；「是改目标还是改结构」交回决策者，不写「上限就是这个数」。
