# 接入后同步消费方

主执行方先填 `target_root` 源码副本和本批可改的消费文件清单。先读目标
`skills/game-design-theory/SKILL.md` 选卡表、工作目录的 `Paths.card_plan`、[../workdir.md](../workdir.md)。
以读者任务为接替单位，不能把一份旧参考所有引用都机械换成同一张卡。

接入前准备 quick_ref_file、description_file、锚点、entry_groups、old_files、rulings 和 residue_allow。
每条内容裁决有 why，保留来源限制；不要把本书的一次裁决加到通用替换表。
先运行材料检查，再生成和扫描本次写出的文件：

```text
python scripts/check_cards.py <workdir>
python scripts/integrate.py <workdir>
```

integrate 只负责卡、notes、入口和配置列出的旧文件，不替你改 agent 或其他 skill，不重写/扫描无关参考。
先在隔离候选源码副本里接替；最终是否迁移等口径 B 验收，不把候选生成当迁移批准。
旧文件仍承担未接替任务时保留，只删已接替部分；最后一个任务已接替且验收通过才删文件。
old_files 只列本候选中计划完整接替的文件，部分迁移要重新定实际组合并验证它。

逐处搜索旧文件名和旧摘要，查看 agent、设计讨论入口、技能正文、模板和测试等实际消费方。
每处按那一行的任务直接链到 1–3 张最合适的卡，泛指本书资料的可指选卡表；保留原有路径写法。
一跳直达，不留旧文件名索引壳；选卡表写近邻区分，不排除其他有效路线。
更早加载的速查、agent 自带规则若与卡冲突，同次修正；经验估计不能继续写成事实。
把新增任务的去处补到实际消费入口，别只改资料目录。

主执行方在目标源码副本跑其引用链测试和相关测试（例如本仓库的 `scripts/tests/test_reference_links.py`），
并搜索确认旧引用清零、每个新链接存在且对口；脚本只核存在，人工核任务对应。
重复生成比本次文件字节；tag 对照用 Git 暂存后的形式比较，并另核生成文件原始字节，
不能为了比较重写无关文件。公开化后抽读转换过的句子，残留为零不等于语义保真。

Codex 用户的导出 agent 在项目外部，不会随插件更新；交接提醒重新运行仓库的
`scripts/export_codex_agents.py`，再开新会话。未经授权不修改他人的项目副本。
链接断、任务指错、旧摘要冲突或确定性检查失败就停，修后重跑，再交候选内容评审。
交回：改动文件及引用映射、摘要口径变化、测试命令和退出码、导出提醒、未决；不自行发布。
