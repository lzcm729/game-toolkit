# 阶段 0：完整阅读并列读者任务

主执行方先填负责章节/行段、工作目录、输出笔记文件。读 [../method.md](../method.md) 的整书理解和阅读约定，
只依据工作目录下的 `Paths.source`。分段完整读完，截断就缩小范围重读；不能只看标题或页边要点。
前言、部分引言和附录也列去向。转换缺损单记，自己的批判标「我的判断」或待核。

每章笔记写到工作目录的 `stage0-notes/<段>.md`：主旨、一级论点及关系、作者术语、核心命题及页码、
证据类型、时代前提/盲点/未证假设、应用潜力、重要案例。术语按作者用法，不用常识替代定义。
任务宁多勿漏，但每条能回原文；不为数量编方法或批判。

```markdown
| task_id | 读者任务 | 原文位置 | 预期交付物 | 重要性及依据 | 尚缺条件 |
|---|---|---|---|---|---|
| t01-01 | 比较两次影子 | Ch1 Observe, p.1 | 条件与差异记录 | 高，条件变化会使比较失效 | 表格格式未给 |
```

主执行方合成 `Paths.overview`：整书主旨、结构、术语、批判、逐章摘要和完整任务表。
跨段任务号统一，保留来源与不同条件；不从旧参考或已通过单元反推任务范围。

```text
python scripts/stage1.py tasks <workdir>
```

编号重复、任务表空、负责范围没读全就停；修正后重跑同一检查。
向用户交范围和重点确认，已有明确委托时沿用；未确认不进入批量提取。
交回：笔记/overview 路径、各章任务数、检查命令与结果、截断或材料缺损、最不确定的判断；不粘贴全文。
